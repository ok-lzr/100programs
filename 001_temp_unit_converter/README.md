## 为什么做它

## 关卡 1 · 让它先会算

**建议用时**：20 分钟

### 做出这样就算过

运行后屏幕上出现一行：100.00°C = 212.00°F。两个数字都得是程序算出来的，不是你手打进去的。

### 怎么想（步骤）

1. 在 001_temp_unit_converter 文件夹里新建一个 temp_conv.py，这就是你唯一要写的文件
2. 起两个变量：一个存摄氏温度（先给 100），一个存算好的华氏温度。换算公式是 华氏 = 摄氏 × 9 ÷ 5 + 32
3. 用 print 把两个数按「摄氏 = 华氏」的样子打出来，两边都保留两位小数
4. 把摄氏那个变量的值改成 0，重新运行，看输出有没有跟着变成 32.00
5. 再改成 37，看是不是 98.60

### 要用到的语法点

- **变量**：给一个值起名字存起来，名字要看得懂，比如 celsius 比 a 好
- **算术运算与优先级**：先乘除后加减，想改顺序就用圆括号；除法用 / 会得到小数
- **f-string**：字符串前面加个 f，里面的花括号会被换成变量的值
- **保留两位小数**：在花括号里加一个冒号，再写 .2f，意思就是保留两位小数
- **print**：想一次打出几段内容，用逗号隔开就行

### 做完了自己检查

- [x] 100 转出来是 212.00
- [x] 0 转出来是 32.00
- [x] 37 转出来是 98.60
- [x] 改温度时只改了一个地方，另一个数字自动跟着变

### 卡住看这里

- 结果不对就先手算一遍 100×9÷5+32 等于多少，跟程序输出对一下，能立刻看出是哪一步错了
- 如果输出是 212 而不是 212.00，说明你还没用上保留两位小数的写法
- 如果算出 212.0 但带着一堆多余的小数位，检查冒号后面写的是不是 .2f

### 常见坑

- 公式记反：写成 (摄氏 + 32) × 9 ÷ 5 是拿华氏算摄氏的公式
- 9÷5 心算成 1（整数思维），实际要写成小数才对

## 关卡 2 · 让它开口问你

**建议用时**：25 分钟

### 做出这样就算过

程序先问「请输入摄氏温度」，你输入 36.6，它回一行 36.60°C = 97.88°F。输入 100 就回 212.00。

### 怎么想（步骤）

1. 把写死的摄氏值换成 input，程序运行时才问你
2. input 拿回来的东西是文字，不是数字。用 float 把它变成小数再参与计算（拿文字做乘法 Python 会报错）
3. 把问句写清楚一点，比如让对方知道可以输小数
4. 先故意输入 abc 跑一次，看看报错信息长什么样，记住这个错的名字
5. 再输入 36.6 跑一次，确认结果是 97.88

### 要用到的语法点

- **input()**：程序会停下来等你在下面打字，按下回车才继续；它拿回来的永远是文字
- **float()**：把文字变成小数；int() 是变成整数，但温度会有小数，用 float
- **类型错误**：文字和数字不能直接做乘法，Python 会报 TypeError —— 见到它八成是忘了转换
- **try / except（先认识一下）**：把可能出错的代码放在 try 里，出错时跳去 except 而不让程序崩掉；这一关不写也行，下一关要用

### 做完了自己检查

- [x] 输入 100，输出 212.00
- [x] 输入 36.6，输出 97.88
- [x] 输入 0，输出 32.00
- [x] 你知道输入 abc 时程序为什么会崩，也知道是哪一行崩的

### 卡住看这里

- 报错里有 can only concatenate str …… 说明你在拿文字做加法，检查有没有先转成小数
- 报错里有 could not convert string to float，说明你输入的内容本身不是数字（比如多打了一个单位符号）
- 程序一闪就没了？在最后加一句等待输入的语句顶住窗口，或者用编辑器的运行窗口看输出

### 常见坑

- 只转换了一半：比如算的时候转了，打印的时候又用了原来那个文字变量
- 把问句写成 input 的参数时忘了加引号，Python 会去找一个不存在的变量

## 关卡 3 · 两个方向都能转

**建议用时**：30 分钟

### 做出这样就算过

程序问：转成 F 还是 K？输 F 得到华氏，输 K 得到开尔文，输别的东西它会说「只认识 F 和 K」并且不崩。100°C → F 是 212.00，→ K 是 373.15。

### 怎么想（步骤）

1. 再拿一个 input 问目标单位
2. 用 if / elif / else 分三支：F 走华氏公式，K 走开尔文公式（开尔文 = 摄氏 + 273.15），其它一律走 else 提示一句
3. 用户可能打 f、F、还可能前后带空格。先把输入两头的空格去掉、再统一转成大写，然后才比较
4. 输出行里的单位符号要跟着变：转成华氏就写 °F，转成开尔文就写 K
5. 三个测试各跑一次：100 F、100 K、100 X

### 要用到的语法点

- **if / elif / else**：从上往下挑第一个成立的分支执行，一个都不成立才走 else；elif 可以有好几个
- **比较运算符**：判断相等用两个等号；一个等号是赋值，两个才是比较
- **字符串方法**：去掉两头空白和统一成大写各有一个现成方法，不用自己写循环
- **or**：两个条件满足一个就算成立，可以用它同时接受 F 和 f

### 做完了自己检查

- [ ] 输入 100 和 F，输出 212.00
- [ ] 输入 100 和 K，输出 373.15
- [ ] 输入 100 和 X，提示只认识 F 和 K，程序没有崩
- [ ] 输入前后带空格的 f（比如「 f 」）也能被认出来
- [ ] 输入小写 f 也能被认出来

### 卡住看这里

- 明明输了 F 却走了 else？把用户输入原样打印出来看一眼，很可能带着空格或回车以外的东西
- 两个分支都想执行？检查是不是把第二个写成了新的 if，而不是接在后面的 elif
- 想让程序在提示之后继续问，而不是直接结束？这一关可以先结束，下一关的循环会解决它

### 常见坑

- 用了一个等号做比较，那是在赋值，条件永远成立
- 分支顺序写反：把 else 写在 elif 前面，后面的分支就永远轮不到
- 只处理了大写，忘了统一处理

## 关卡 4 · 做成能反复用的函数

**建议用时**：35 分钟

### 做出这样就算过

程序能一直换算，直到你输入 q 才退出；退出时打印「本次共换算 3 次」。而且两个换算公式在代码里各只出现一次。

### 怎么想（步骤）

1. 把「摄氏转华氏」和「摄氏转开尔文」各写成一个函数：给它一个摄氏值，它把结果交回来，自己不打印
2. 主流程改成一个永远成立的循环：问温度 → 问单位 → 调函数 → 打印结果
3. 在问温度之前先让用户可以退出：输入 q 或 quit 就跳出循环
4. 加一个计数变量，每成功换算一次就加 1，退出循环后打印总次数
5. 连转三次（100 F、0 F、37 K）再输 q，看总数是不是 3

### 要用到的语法点

- **def 定义函数**：给一段反复用的逻辑起个名字，括号里写它需要什么，函数体缩进
- **return 返回值**：把算好的结果交回给调用它的地方；没写 return 的函数交出的是「空」
- **while True 与 break**：永远成立的循环靠 break 跳出去；跳出去之后循环后面的代码会继续跑
- **计数变量**：循环外面先让它等于 0，每次成功就加一；写在循环里面会被反复重置
- **continue（可选）**：跳过本轮剩下的部分，直接开始下一轮

### 做完了自己检查

- [ ] 连续换算 3 次后输 q，显示 3 次
- [ ] 输 q 能干净退出，控制台没有红色报错
- [ ] 两个换算公式各自只在函数里出现一次，主流程里没有重复的公式
- [ ] 函数里没有再打印结果（结果只由主流程打印一次）

### 卡住看这里

- 结果被打印了两遍？说明函数里也打印了，函数只该负责算
- 计数永远是 0 或 1？很可能计数器写在了循环里面，每轮都被重新变成 0
- 函数报 NameError？Python 从上往下执行，函数必须先定义、后调用
- 输 q 之后还在问单位？退出的检查要放在第一次提问之前

### 常见坑

- 函数名用了拼音缩写，过两天自己都看不懂
- 在函数里直接修改外面的变量，导致计数行为难以预料——用 return 交出来更清楚
