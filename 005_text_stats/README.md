# 005 · 文本统计器

> ★☆☆☆☆　难度 1.0 / 5　·　001–020 · 找回手感
> 3 小时左右，分 4 次　·　1 个文件（text_stats.py），约 140 行　·　只用 Python 自带功能
>
> **规矩：这份任务卡只给思路和语法点，一行代码都没有。代码由你自己写。**

**一句话**：数清一篇文字有多少字、多少词、谁出现最多

## 为什么做它

你写过作文之后应该都有过这个念头：我这篇到底多少字？老师说的「用词重复」具体是哪个词重复了几次？这个项目从「数一行字」一路做到「读一个文件、排出词频前五名」，中间会踩到中英文处理的真实差别。词频统计几乎是所有文本分析的第一步，做完它你就摸到门槛了。

## 做完是什么样

程序能读一个 txt 文件（或直接读你粘贴的一段文字），输出一份统计报告：总字符数、去掉空格的字符数、中文字数、英文单词数、行数，还有出现次数最多的前五个词及各次数；报告还能另存成一个文件。约 140 行，一个文件。

## 会练到的语法

`字符串方法 split / lower / strip`　`字典计数`　`for 遍历`　`文件读取`　`排序（按值排）`　`列表与元组`　`函数与返回值`　`字符判断（中文的范围）`

> 核心是「用字典数数」：这是最常用的一招，出现一次就在字典里给这个键加一。

## 关卡 1 · 先数清一行字

**建议用时**：20 分钟

### 做出这样就算过

程序里写死一段文字（中英文混着来），运行后输出：总字符数、去掉空格后的字符数、中文字数、英文单词数。

### 怎么想（步骤）

1. 新建 text_stats.py，先写死一段测试文本，中英文和标点都放一点
2. 总字符数直接用现成的长度函数就能得到
3. 去掉空格后的长度：想清楚是「先把空格换成空内容」还是「只把非空格字符挑出来」，两种都试
4. 中文字数：遍历每个字符，判断它是不是落在中文的范围里（汉字的编码区间），是就计数加一
5. 英文单词数：按空格切开后数个数，但注意标点会跟着词一起被切出来，先不管，下一关再收拾

### 要用到的语法点

- **len()**：能数出字符串有几个字符、列表有几项
- **字符串替换**：把某段内容换成另一段，换成空内容就等于删掉它
- **for 遍历字符串**：循环能一个字符一个字符地拿出来处理
- **字符编码范围判断**：中文字符的编码落在一个特定区间里，可以用大小比较判断某个字符是不是中文
- **计数器变量**：循环外先归零，符合条件就加一

### 做完了自己检查

- [ ] 总字符数跟你用肉眼数的结果一致
- [ ] 去掉空格后的数字比总数小，差的就是空格个数
- [ ] 中文字数跟文本里汉字的个数一致（标点不算）
- [ ] 英文单词数大约等于空格分隔的段数

### 卡住看这里

- 中文字数统计成 0：判断范围写错了，可以先打印每个字符看看它们的编码范围落在哪里
- 中文标点被算进汉字：中文标点的编码和汉字相邻但不同区间，需要再排除一部分
- 英文单词数偏大：标点被当成词的一部分了，这一关先接受，下一关清理

### 常见坑

- 用长度函数数出来的字符数包含了换行和空格，跟「字数」不是一回事
- 把中文判断写成判断编码大于某个值，结果把英文标点也算进去了

## 关卡 2 · 把词切干净再数

**建议用时**：35 分钟

### 做出这样就算过

运行后能看到：标点全被换成了空格、字母统一成小写，China 和 china 被算成同一个词；再统计一次英文单词数，比上一关更准。把清洗后的文本打印出来看一眼，就知道对不对。

### 怎么想（步骤）

1. 想清楚哪些字符算标点（逗号、句号、问号、感叹号、引号、括号等），准备一个标点字符集
2. 遍历文本，遇到标点就换成一个空格；这一步做完，词和词之间就只剩空格分隔了
3. 把所有字母统一转成小写，这样大小写不同的同一个词不会各算一次
4. 把连续的多个空格合并成一个，再去掉两头的空白
5. 重新统计英文单词数，跟上一关的结果对比，看差在哪

### 要用到的语法点

- **字符串集合与遍历**：把所有标点写成一个字符串，遍历文本时逐个检查
- **字符串方法 .lower()**：把所有字母变成小写
- **split() 的默认行为**：不给参数时它会自动按任意空白切分并忽略连续空白，比按单个空格切更好用
- **列表推导或循环拼接**：把处理后的字符重新攒成一个字符串，两种写法都行
- **函数封装清洗步骤**：清洗逻辑写成一个函数，输入原文返回干净的文本，方便反复调用和测试

### 做完了自己检查

- [ ] 文本里的逗号句号都被换成了空格
- [ ] China、china、CHINA 被算成同一个词
- [ ] 连续空格不会产生空字符串（空的词不该被计数）
- [ ] 清洗函数对空字符串输入也不报错

### 卡住看这里

- 切分后列表里出现一堆空字符串：用不带参数的切分方法，它会把连续空白当成一个分隔符
- 标点没被清掉：中文标点和英文标点是两套，检查你的标点集里两种都写了吗
- 把所有字符都换掉了导致文本空了：替换时只处理标点集合里的字符

### 常见坑

- 在遍历文本的同时修改原字符串，导致漏掉字符（正确做法是拼出一个新字符串）
- 只处理了英文标点，中文逗号句号还留在词里

## 关卡 3 · 用字典数出词频

**建议用时**：30 分钟

### 做出这样就算过

程序输出每个词出现了多少次，并且按次数从多到少排出前五名，格式是「第 1 名：的 出现 12 次」。

### 怎么想（步骤）

1. 把清洗后的文本切成一串词
2. 准备一个空字典，遍历这串词：如果这个词已经在字典里就把它的数加一，不在就把它加进去并且记为 1。用字典自带的取值带默认值的方法可以让这一步更短
3. 遍历完字典就得到了「词 → 次数」的完整统计
4. 排序：字典本身没有顺序，先把它变成一串键值对，再按值从大到小排。排完取前五个
5. 打印时带上名次和次数；中文词和英文词一起排也没问题

### 要用到的语法点

- **字典计数**：遇到一个词就给它加一，这是词频统计的标准套路
- **字典的 get 方法**：取值时可以给一个默认值，取不到就返回默认值，能省掉一个判断
- **把字典转成键值对列表**：排序前先转一下，字典自己不能直接按值排
- **sorted 的排序键参数**：可以告诉排序函数「按第几项排、是不是从大到小」，这样就能按出现次数排
- **切片取前几个**：排序完只取前面五个

### 做完了自己检查

- [ ] 总次数加起来等于词的总数（可以自己验算）
- [ ] 出现最多的词排在第一，次数正确
- [ ] 只出现一次的词也在统计里，没有丢
- [ ] 前五名不足五个时（文本很短）程序不报错

### 卡住看这里

- 排序后结果不对：检查排序键指的是次数那一项，并且指定了从大到小
- 报错说不能比较：键值对里的名字和数字被搞混了，先确认你的排序键取的是数字
- 词频里全是空格或者空字符串：清洗那一步没做干净，回上一关检查

### 常见坑

- 对字典直接排序（要先转成键值对）
- 忘了处理大小写，导致同一个词被拆成好几份

## 关卡 4 · 读真文件，出报告，还能存下来

**建议用时**：35 分钟

### 做出这样就算过

运行程序时给它一个 txt 文件路径（在同一个文件夹里放一个测试文件），它读完整个文件输出完整报告；再加一个参数或一次询问，把报告保存成另一个 txt；文件不存在时给出清楚提示，不崩。

### 怎么想（步骤）

1. 用 input 问文件路径，或者直接写死一个文件名，先跑通
2. 读文件时指定编码（UTF-8），一次读全部内容；文件不存在时用 try / except 接住并提示
3. 把前几关的功能串起来：清洗 → 统计基础数量 → 词频前五 → 组装成一份多行报告
4. 把报告打印出来，同时问一句要不要保存；要保存就写进一个新文件（写的时候也指定编码）
5. 自己造三个测试文件验证：一个纯中文、一个纯英文、一个空文件。空文件不能让程序崩

### 要用到的语法点

- **打开与读取文件**：打开后读取全部内容，用完要关闭；用 with 的写法能自动帮你关
- **文件不存在的异常**：路径写错时 Python 会抛出专门的错误类型，接住它然后提示用户
- **写入文件**：写入时同样指定编码，中文才不会是乱码
- **多行字符串组装**：报告内容可以先攒成一个列表，每行一项，最后一次性拼起来
- **除零保护**：空文件会让「平均每行多少字」这类计算除以零，先判断总数是不是 0

### 做完了自己检查

- [ ] 中文文件：中文字数正确，词频能列出高频字或词
- [ ] 英文文件：单词总数比前几关更准
- [ ] 空文件：程序输出「文件是空的」之类的提示，不报错
- [ ] 路径不存在：清晰提示找不到文件
- [ ] 保存的报告文件能打开且不乱码

### 卡住看这里

- 读出来的中文是乱码：读取时指定 UTF-8；如果文件本身是别的编码，试着换一个编码名再读
- 报告里的数字有小数点后十几位：格式化时控制小数位
- 行数统计不对：注意最后一行有没有换行符，以及空行的处理要不要算进去——你自己定规则，然后写进报告里说明

### 常见坑

- 读完文件忘了关闭（用自动关闭的写法最省心）
- 把统计结果直接覆盖写到源文件上，原始素材没了
