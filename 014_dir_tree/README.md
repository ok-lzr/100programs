# 014 · 目录树导出器

> ★½☆☆☆　难度 1.5 / 5　·　001–020 · 找回手感
> 3 小时左右，分 4 次　·　1 个文件（dir_tree.py），约 150 行　·　只用 Python 自带功能
>
> **规矩：这份任务卡只给思路和语法点，一行代码都没有。代码由你自己写。**

**一句话**：把一个文件夹的结构画成树，导出成文本或 Markdown

## 为什么做它

给别人看一个项目的结构时，一张目录树比说十句话都清楚；自己整理资料时，也需要先看清「我到底把东西放成了什么样」。这个项目看起来简单，但它藏着编程里最重要的一招：**递归**——函数自己调用自己。第一次写递归都会有点晕，写完你会觉得挺妙。

## 做完是什么样

程序给一个文件夹路径，输出它的目录树：文件夹在前、子项缩进、文件夹后面带一个斜杠标记；可以选择输出到屏幕或者写进一个 Markdown 文件；能跳过隐藏文件夹和缓存目录；还能只展开前几层。最后附带统计：多少文件夹、多少文件、一共多大。约 150 行，一个文件。

## 会练到的语法

`函数递归`　`函数调用自己`　`缩进字符串`　`路径拼接`　`判断文件与文件夹`　`列表过滤`　`写入文件`　`读命令行参数`　`大小单位换算`　`排序`

> 新东西是递归：函数内部调用自己，用来处理「一层套一层，不知道有几层」的结构。这是本阶段最烧脑的一关，卡住很正常。

## 关卡 1 · 先只看一层

**建议用时**：20 分钟

### 做出这样就算过

运行后给一个文件夹路径，打印它里面每一项的名字：文件夹的名字后面带一个斜杠，文件不带。先文件夹、后文件，各自按名字排序。最后打印一句「共 6 项，其中文件夹 2 个」。

### 怎么想（步骤）

1. 新建 dir_tree.py，随便挑一个文件夹当目标（建议用你刚写完 013 的项目文件夹，里面有东西可看）
2. 遍历这个文件夹里的每一项，把文件夹和文件分成两组
3. 两组各自排序，然后先打印文件夹那组，再打印文件那组
4. 给文件夹后面加一个斜杠做标记，文件原样打印
5. 最后统计两项数量。注意：这一关只做第一层，子文件夹里的内容先不管

### 要用到的语法点

- **路径对象**：用 pathlib 造一个路径，它自带遍历、判断类型、取名字的能力
- **分成两组**：遍历时按「是不是文件夹」放进两个列表
- **排序**：列表自带排序；中文和英文混在一起时排序结果可能不合你的直觉，属于正常
- **字符串拼接**：给文件夹名字后面加一个斜杠，只是显示上的标记
- **取数量**：列表有多少项，一问就知道

### 做完了自己检查

- [ ] 文件夹排在文件前面，各自有序
- [ ] 文件夹名字后面有斜杠标记
- [ ] 数量统计和你手工数的一致
- [ ] 路径不存在时给提示不崩

### 卡住看这里

- 报错说不是文件夹：确认路径指的是文件夹本身，而不是里面某个文件
- 斜杠加错了位置：要加在文件夹名字后面，不是前面
- 顺序看着乱：按名字排序时，大写字母和小写字母、中文英文的顺序规则不一样，属正常现象

### 常见坑

- 把「打印一个斜杠」和「路径本身拼接」搞混，导致斜杠被写进了真实路径里
- 忘了处理路径不存在的情况

## 关卡 2 · 让它一层层钻进去

**建议用时**：40 分钟

### 做出这样就算过

输出完整的目录树：每深一层，前面就多缩进两个空格；文件夹先列、文件后列；每行前面加上表示层级的短横线。跑完你项目的文件夹，应该像一张真正的树状目录。

### 怎么想（步骤）

1. 先想清楚递归的结构：写一个函数，给它「一个文件夹」和「当前层数」，它负责打印这个文件夹里的内容
2. 打印每一项时，缩进量等于层数乘两个空格——用字符串乘法比写循环简单
3. 碰到文件就打印完事；碰到子文件夹，先打印它自己，然后**调用同一个函数**，把子文件夹和层数加一传进去
4. 先只用两三层文件夹测试，确认缩进对；再跑大一点的文件夹
5. 加一个层数上限保护：如果传进来的层数超过某个值就不再往下钻（防止意外的深层嵌套）

### 要用到的语法点

- **递归**：函数在处理子文件夹时调用它自己——每一层都做同样的事，所以同一个函数就够
- **缩进用字符串乘法**：空格字符串乘层数，就是要缩进的长度
- **层数参数**：递归时把层数加一传下去，它就是「我现在在哪一层」的记号
- **递归的出口**：碰到文件就不再往下调用了；另外还要有一个层数上限，否则万一目录结构有环就会无限递归
- **路径拼接**：把子项的名字接到父文件夹路径后面，得到子项的完整路径

### 做完了自己检查

- [ ] 每一层的缩进都比上一层多两个空格
- [ ] 同一个文件夹里，文件夹排在文件前面
- [ ] 用你自己项目的文件夹跑一遍，对照你印象里的结构是对的
- [ ] 层数上限生效：到了指定层数就不再往下展开
- [ ] 空文件夹也能正常显示

### 卡住看这里

- 只打印了一层就停了：递归调用写在了循环外面（那只会处理最后一个子文件夹）
- 缩进一直不变：层数没有加一就传下去了
- 程序卡住不出结果：递归没有出口，检查是不是连文件也往下调用了；先按中断键停下来，把层数上限调成 2 再排查

### 常见坑

- 递归调用忘记加层数，导致每一层都从零开始记
- 打印语句和递归调用的顺序写反，导致子文件夹的内容出现在它自己前面

## 关卡 3 · 导出成文件，还要会躲开没用的东西

**建议用时**：30 分钟

### 做出这样就算过

程序能把树写进一个 Markdown 文件（.md），文件里第一行是文件夹名当标题，缩进用 Markdown 的列表符号表示；自动跳过隐藏文件夹、缓存文件夹这些不想看的内容；跑完告诉你「已写入 42 行」。

### 怎么想（步骤）

1. 把「输出一行」这件事变成一个统一的出口：要么打印到屏幕，要么存进一个列表最后写文件。推荐先全部存进列表，最后一次性写——这样两种输出模式只需要一个开关
2. 加忽略名单：名字以点开头的（隐藏文件）、还有缓存目录这类，遇到就跳过不打印也不往下钻
3. 树的行前缀改成 Markdown 的列表符号，缩进就用两个空格加短横线，这样在支持 Markdown 的地方看起来就是一棵树
4. 写文件时第一行写标题，指定编码，用覆盖模式（每次都要一份全新的）
5. 写完打印总行数和文件路径，方便你去找

### 要用到的语法点

- **列表收集后统一输出**：把每一行先攒进列表，最后决定打印还是写文件——比在递归里直接打印灵活得多
- **名字开头判断**：用字符串的开头判断方法就能识别隐藏项
- **忽略名单**：把要跳过的名字放一个集合里，判断起来最快也最好改
- **写入文件**：写好编码，用换行把所有行连起来一次写入
- **统计行数**：列表长度就是行数

### 做完了自己检查

- [ ] 生成的 .md 文件里，标题在最上面，缩进结构跟屏幕输出一致
- [ ] 隐藏文件夹和缓存目录没有出现在结果里
- [ ] 文件能正常打开，中文不乱码
- [ ] 写入的行数跟屏幕上打印的行数一致
- [ ] 同一个文件夹跑两次，生成的文件内容完全一样

### 卡住看这里

- 文件里所有内容挤在一行：把列表写进文件时要用换行符连接，或者每行自己带换行
- 缓存目录还是被列出来了：忽略名单写成了完整路径，应该只比较名字
- 中文乱码：写入时没指定编码

### 常见坑

- 边递归边写文件，导致文件被反复打开关闭（先攒列表再写，快也稳）
- 把忽略名单写成了「包含」而不是「开头是」，结果误伤名字里带点的正常文件

## 关卡 4 · 加统计、加参数，做成随手能用的工具

**建议用时**：35 分钟

### 做出这样就算过

运行时可以在命令后面带参数：一个参数是文件夹路径，第二个是最大层数，第三个决定要不要写文件。不带参数时用默认值（当前文件夹、全部层数、只打印）。最后总是打印三行统计：文件夹数、文件数、总大小（自动用 KB 或 MB 显示）。

### 怎么想（步骤）

1. 从运行参数里读用户输入：第一个是路径，后面两个是可选参数，缺省时用默认值
2. 递归的时候顺便统计：每碰到一个文件夹就加一，每碰到一个文件就加一、并把大小累加进总数
3. 统计变量要么用列表包一层传进递归（因为函数内部改不了外面的数字），要么让递归函数把统计结果返回上去。两种都试试，选你觉得清楚的那种
4. 把总字节数换算成合适的单位：超过 1024 的 KB 就显示 MB，保留一位小数
5. 最后整理输出格式：树、然后空一行、然后三行统计，看起来像一份正经报告

### 要用到的语法点

- **读运行参数**：从 sys 里能拿到运行时写在后面的参数，是一串字符串；下标 0 是脚本自己的名字
- **默认值**：参数个数不够时用默认值，程序不会因为少写一个参数就崩
- **把数字转成整数**：参数拿到的都是文字，层数要转成整数才能比较
- **递归里累计**：在函数里累加外面的数字会失效，用列表当容器或者让函数把结果返回上去
- **单位换算**：用循环反复除以 1024，除到小于 1024 为止，同时换单位名

### 做完了自己检查

- [ ] 带参数运行能生效，不带参数也能用默认值跑
- [ ] 统计的三个数字跟实际情况一致（文件数用系统的属性面板核对）
- [ ] 总大小自动换单位，不会出现 1048576 KB 这种
- [ ] 层数参数写成 1 时只显示第一层
- [ ] 参数写错（比如层数写了字母）给提示，不崩

### 卡住看这里

- 统计永远是 0：多半是用了普通变量在函数里累加，改成列表容器或者返回值
- 总大小显示成好几位小数：换算完记得保留一位
- 参数顺序搞混：在程序开头就把三个参数读出来起好名字，后面别再用下标

### 常见坑

- 统计时把文件夹也算进了总大小（文件夹本身没有大小）
- 默认路径用了当前目录，结果不小心把一个巨大的文件夹扫了一遍——先用小文件夹测试
