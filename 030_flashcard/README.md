# 030 · 单词记忆卡片

> ★★☆☆☆　难度 2.0 / 5　·　021–040 · 联网与窗口
> 3 ~ 4 小时，分 4 次　·　1 个文件（flashcard.py）+ 一个自动生成的词库文件，约 190 行　·　只用 Python 自带功能
>
> **规矩：这份任务卡只给思路和语法点，一行代码都没有。代码由你自己写。**

**一句话**：背单词：认识的不常出现，不熟的反复出现

## 为什么做它

这一关是本阶段的收官，也是第一个「会自己安排学习计划」的程序。核心是一句话：**不熟的词多考你几遍，熟了的词过几天再问**——这叫间隔重复，很多背单词 App 的灵魂就是这个。做完它你不光有一个能用的背单词工具，还理解了「用规则代替死记」这件事。

## 做完是什么样

程序从词库里抽卡片：先显示英文，按回车看中文和例句；然后你选「记得」或「不记得」，它自动更新这个词的熟悉度并安排下次出现的时间；菜单里能加新词、看哪些词最不熟、看今天学了多少张、连续学习多少天。所有数据存在文件里，关掉再打开还在。约 190 行，一个文件。

## 会练到的语法

`列表里放字典`　`随机挑选`　`按条件排序`　`文件存读`　`日期与时间比较`　`菜单循环`　`统计与计数`　`输入校验`　`用户输入的等待`　`连续天数统计`

> 新东西是「用数据驱动行为」：卡片什么时候出现不靠随机，而靠每个词自己的熟悉度和上次出现时间算出来。你的程序第一次有了「策略」。

## 关卡 1 · 先做出一张卡

**建议用时**：25 分钟

### 做出这样就算过

词库里内置十几个单词（英文、中文、例句），运行后随机抽一个：先只显示英文，按回车之后显示中文和例句，然后再按回车抽下一张。连抽五张，五张不重样（至少在这五张里不重复）。

### 怎么想（步骤）

1. 新建 flashcard.py，把词库写成一个列表：每一项是一个字典，字段是英文、中文、例句
2. 先随机抽一张，只显示英文那一面
3. 用输入功能做一个「等一下」的效果：不输入任何内容直接按回车，就显示背面（中文和例句）
4. 背面显示完再按一次回车，抽下一张
5. 用一个循环做五轮。暂时不管重复的问题，先让流程跑通

### 要用到的语法点

- **列表里放字典**：一个词三个字段，字典比用列表按下标取清楚得多
- **随机挑选**：从列表里随机取一项，有现成功能
- **输入当暂停**：用输入功能让程序停住等你按回车，这是命令行程序最常用的「翻卡」方式
- **循环出题**：用循环控制抽几张，循环变量可以当序号用
- **打印分隔线**：每张卡之间打一条线，屏幕看起来清爽

### 做完了自己检查

- [ ] 卡片正面只有英文，背面有中文和例句
- [ ] 按回车能正确翻面和进入下一张
- [ ] 连抽五张，能看到不同的单词
- [ ] 词库为空时给提示，不崩
- [ ] 整个流程不用重启程序就能连续做五张

### 卡住看这里

- 按回车没反应：输入功能的返回值你没接住，程序其实在等输入，只是没提示——先打印一句「按回车继续」
- 正面就显示了中文：两个面都打印了，检查顺序和条件
- 一次抽到同一个词很多遍：随机本来就是可能重复的，下一关会处理

### 常见坑

- 把词库写成了三段互相对应的列表（英文一个列表、中文一个列表）——三处一旦错位就全乱了，用字典最稳
- 忘了给用户提示「按回车」，界面看起来像卡住了

## 关卡 2 · 打分，并且记住

**建议用时**：30 分钟

### 做出这样就算过

翻完背面后程序问「记得吗？（1 记得 2 不记得）」，根据回答更新这个词的熟悉度（记得加一、不记得减一但最低到零），并把结果写回词库文件。重启程序后再抽几轮，你能看出不熟的词出现得更频繁。

### 怎么想（步骤）

1. 给每个词加两个字段：熟悉度（从 0 开始）和上次出现时间（先留空）
2. 翻面之后问一句，根据输入更新熟悉度；输入非法值就再问一遍
3. 抽卡时不要完全随机：熟悉度越高的词被抽中的概率越低。最简单的做法是把词按熟悉度排序后，从前一部分里随机抽（比如只在前三分之二里抽）
4. 抽完一张就立刻把整个词库写回文件——**别等退出才写**，强制关闭就全丢了
5. 测试：故意对某几个词一直选「不记得」，观察它们是不是出现得更频繁

### 要用到的语法点

- **增加字段**：直接往字典里加新的键就行，不用改结构
- **按字段排序**：列表可以按每个字典里的某个字段排序
- **从前一部分里抽**：排序后切片取前面若干项，再从中随机抽——这就实现了「不熟的更容易出现」
- **分数下限**：减分时不要低于零，用一个最大值判断
- **每次修改就保存**：抽完一张就写文件，避免丢数据

### 做完了自己检查

- [ ] 选「记得」之后，那个词的熟悉度确实加了一（打开文件看）
- [ ] 连选几次「不记得」，熟悉度减到 0 就不再减
- [ ] 不熟的词出现的次数明显更多（做二十张感受一下）
- [ ] 中途强制关掉程序，重新打开后分数还在
- [ ] 输入 3 或者字母时会重新问，不会崩

### 卡住看这里

- 分数没变：更新的是内存里的字典，但写文件时写的是旧数据（或者压根没写）
- 所有词出现频率一样：排序或切片没生效，把抽卡前的候选列表打印出来看看
- 重启后分数归零：词库文件路径不对，或者写入时被覆盖成了初始数据

### 常见坑

- 把熟悉度只存在内存里（关掉就没了，白背）
- 只在退出时保存（强制关闭是常事）

## 关卡 3 · 加上时间：熟的隔几天再问

**建议用时**：35 分钟

### 做出这样就算过

运行后能看到明显的差别：刚打过「不记得」的词马上就又出现，而熟悉度高的词抽过一次之后短时间内不再出现（熟悉度 3 以上隔一天、5 以上隔三天）；如果所有词都还没到时间，屏幕显示「今天的卡都复习完了」并列出最近三张的到期时间。

### 怎么想（步骤）

1. 每次抽完一张，把这个词的上次出现时间更新成现在，并记录它下次该什么时候出现
2. 算下次时间：熟悉度越高间隔越长。用「现在加上若干天」的方式算，天数按熟悉度分档（比如 0 分当天、1 到 2 分一天、3 到 4 分三天、5 分以上七天）
3. 抽卡前筛选：把所有词分成「今天该复习」和「还没到时候」两组，从第一组里抽
4. 第一组为空时：打印「今天的卡都复习完了」并列出最近的三张什么时候到期
5. 时间比较：存的时候统一存成年月日时分，比较时解析回时间对象再比

### 要用到的语法点

- **算下次时间**：用「现在加上一个天数」的写法得到未来时间，天数按熟悉度查一张小表决定
- **时间解析与比较**：把存的文字解析成时间对象，跟现在比较大小
- **分两组**：遍历词库，按「下次时间是否已到」分别放进两个列表
- **取最近几张**：把还没到期的按时间排序，取前三个显示
- **时间格式化**：显示给别人看的时间写成「10 月 3 日」这种，存的时候用完整格式

### 做完了自己检查

- [ ] 熟悉度高的词抽完之后，短时间内不会再出现
- [ ] 熟悉度低的词会马上再次出现
- [ ] 把所有词的上次时间改成很久以前，它们立刻全部变成「该复习」
- [ ] 全部复习完时提示正确，并列出最近的到期时间
- [ ] 时间显示成人看得懂的样子，不是一长串数字

### 卡住看这里

- 算出来的间隔不对：分档表写错了，或者把小时当成了天
- 时间比较总是成立：解析时格式跟存的格式不一致，两个都打印出来看
- 所有词同时到期：上次时间没被更新，检查是不是只更新了内存没写文件

### 常见坑

- 间隔写得过于复杂（一开始分三四档就够，太复杂你调不动也看不懂）
- 把「上次出现时间」和「下次该出现时间」搞混（存哪个都行，但只能选一个作为依据，别两个混用）

## 关卡 4 · 菜单、统计和连续天数

**建议用时**：35 分钟

### 做出这样就算过

程序有一个菜单：1 开始复习 2 加新词 3 看不熟的词 4 今日统计 5 退出。今日统计显示：今天复习了几张、记得几张、正确率多少、连续学习多少天。连续天数的算法是：学习记录文件里从今天往回数，一天都不缺的次数。

### 怎么想（步骤）

1. 把「复习一轮」做成函数：抽卡、翻面、打分，循环到你不想继续为止
2. 加新词：让用户依次输入英文、中文、例句，检查英文不能和已有词重复，然后写进词库
3. 看不熟的词：按熟悉度排序，列出最低的十个，带上次出现时间
4. 每复习一张就追加一条学习记录（日期、单词、是否记得）。今日统计从这些记录里算
5. 连续天数：把记录里的日期去重、排序，从今天开始往前数，看连续有多少天。今天没学则从昨天开始数（这样白天还没学不会显示成 0）

### 要用到的语法点

- **菜单循环**：老骨架：循环加退出分支，其余走分派
- **追加学习记录**：一行一条，字段用固定分隔符隔开
- **日期去重与排序**：把记录的日期部分取出来放进集合去重，再排序成列表
- **向前数连续**：从今天开始，一天天往前检查在不在集合里，断了就停
- **正确率**：记得的张数除以总张数，注意总数为零时不能做除法

### 做完了自己检查

- [ ] 今日统计的数字跟你实际操作的次数一致
- [ ] 正确率算得对，且今天一张都没复习时不会崩（不能除以零）
- [ ] 连续天数正确：把记录里昨天的日期手工删掉，连续天数应该变成 1
- [ ] 加新词后立刻能在复习里抽到它
- [ ] 看不熟的词列表按熟悉度从低到高排，顺序正确

### 卡住看这里

- 统计把前几天的也算进来了：比较日期时没截取到日那一级
- 连续天数一直显示 0：日期格式和比较方式不一致，把集合里的内容和今天的日期打印出来对比
- 正确率算出小数一大串：格式化保留一位，或者显示成百分比

### 常见坑

- 把学习记录和词库存成一个文件（一个记录状态、一个记录历史，混在一起以后没法看趋势）
- 除法前不判断总数为零（第一天打开程序就会崩）
