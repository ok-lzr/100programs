# 026 · 简易静态文件服务器

> ★★☆☆☆　难度 2.0 / 5　·　021–040 · 联网与窗口
> 3 ~ 4 小时，分 4 次　·　1 个文件（mini_server.py），约 180 行　·　只用 Python 自带功能
>
> **规矩：这份任务卡只给思路和语法点，一行代码都没有。代码由你自己写。**

**一句话**：把自己电脑上的一个文件夹变成能访问的网站

## 为什么做它

「服务器」这个词听起来很重，其实核心就一件事：有人来要东西，你把它给出去。这个项目用自带功能起一个真的服务器，然后用浏览器访问它——你会第一次体验到「我写的东西别人能通过网址打开」。做完它，你就明白网页、链接、状态码、请求日志这些词到底在说什么了。

## 做完是什么样

运行程序后，同一个局域网里的手机或另一台电脑打开你给的地址，就能看到一个文件夹的目录列表，点进去能看文件、能下载；每次访问都会在程序的窗口里打印一行日志（时间、访问的路径、状态码），并且写进日志文件；还能给访问加一个简单口令。约 180 行，一个文件。

## 会练到的语法

`import http.server`　`自定义请求处理`　`处理 GET 请求`　`状态码`　`响应头`　`读取文件并返回`　`URL 编码与中文文件名`　`目录列表生成`　`日志记录`　`口令校验`

> 新东西是「请求与响应」：浏览器先发一个请求（要哪个路径），服务器再回一个响应（状态码加内容）。你会发现整个网页世界就是这么一问一答转起来的。

## 关卡 1 · 先让服务器跑起来

**建议用时**：25 分钟

### 做出这样就算过

运行程序，窗口里打印「服务已启动，请在浏览器打开 127.0.0.1:8000」；用浏览器打开这个地址，能看到你指定文件夹里的文件列表（哪怕只是最简陋的一列文件名）。按中断键能停掉服务。

### 怎么想（步骤）

1. 新建 mini_server.py，引入自带的网页服务功能
2. 先用最省事的方式起一个服务：指定端口和要共享的文件夹，一行就能跑起来，目的是先看到「能访问」这个结果
3. 浏览器打开本机地址加端口，看看默认效果是什么样（它其实已经能用，只是不好看）
4. 把端口换成一个不常用的（比如 8800），确认改端口之后访问地址也要跟着改
5. 故意把端口设成已经被别的程序占用的（比如再跑一个同样的程序），观察报错信息并记下来

### 要用到的语法点

- **import http.server**：自带的网页服务模块，不用装任何东西
- **起服务并指定目录**：可以让服务把某个文件夹当根目录，URL 里的路径就相对它来找
- **端口**：端口就是同一台机器上不同服务的门牌号；被占用了就得换一个
- **一直运行**：服务启动后会一直等着，直到你按中断键
- **中断处理**：接住中断键，打印一句「服务已停止」再退出，别甩一堆报错

### 做完了自己检查

- [ ] 浏览器能打开你给的地址，看到文件列表
- [ ] 换端口后必须用新端口才能访问
- [ ] 端口被占用时报错信息清楚，你能看懂并知道要换端口
- [ ] 按中断键服务能干净停止，不留后台进程
- [ ] 停掉服务后浏览器再刷新就访问不了了（说明真的停了）

### 卡住看这里

- 浏览器打不开：确认程序还在运行、地址里的端口跟代码里一致
- 报错说端口被占用：换一个端口，或者找到占用它的程序关掉
- 访问到的是别的目录：根目录设置的路径写错了，用完整路径更稳

### 常见坑

- 把服务的根目录设成整个硬盘的根（那样别人能看到你所有文件，太危险了）
- 用默认端口 80（需要管理员权限，而且容易和别的软件打架）

## 关卡 2 · 自己写目录页：让它好看又好读

**建议用时**：35 分钟

### 做出这样就算过

自己接手请求处理：访问一个目录时，返回一个自己生成的网页，列出这一层所有文件和文件夹，文件夹显示成可点击的链接并带斜杠，文件显示名字和大小（KB 或 MB）；页面顶部显示当前路径，有一条「返回上一级」的链接。

### 怎么想（步骤）

1. 改成自己处理请求：定义一个继承自带处理器的新类，重写「处理 GET 请求」那个方法
2. 在方法里拿到浏览器请求的路径，把它翻译成硬盘上的真实路径（注意根目录的拼接）
3. 如果这个路径是文件夹：列出里面的内容，生成一段网页文字返回；如果是文件：下一关再处理，先返回一个「暂时不提供下载」的提示
4. 拼网页时把路径处理好：文件夹要带斜杠、链接要指向正确的相对地址、返回上一级的链接要能在根目录时消失
5. 写响应：先写状态码和响应头（告诉浏览器这是网页、内容有多长），再写内容

### 要用到的语法点

- **自定义请求处理类**：继承自带的处理器，然后重写处理 GET 的方法，方法名是固定的
- **取请求路径**：处理器上有现成的属性能拿到浏览器请求的路径
- **路径拼接与安全检查**：把请求路径接到根目录后面；要防止别人用两个点跳到别的目录去
- **发送响应头**：先告诉浏览器状态码和内容类型，再发内容；内容长度要按字节算
- **生成 HTML**：用字符串拼出一段网页，链接用 HTML 的链接标签，注意把特殊字符转义

### 做完了自己检查

- [ ] 访问文件夹时看到的是自己生成的页面，不是默认的丑陋列表
- [ ] 文件夹在页面里可点击，点进去看到下一层
- [ ] 点「返回上一级」能回到上一层；在根目录时这一条不显示
- [ ] 文件显示名字和大小，大小是 KB 或 MB 而不是一长串字节
- [ ] 请求一个不存在的路径时返回 404 页面，而不是报错崩掉

### 卡住看这里

- 页面中文乱码：响应头里要说明用 UTF-8 编码，网页里也要写上
- 点链接进了别的目录：路径拼接时多接或少接了斜杠，把拼好的真实路径打印出来看
- 报错说长度不对：响应头里的内容长度要按字节数算，不是字符数（中文一个字不止一字节）

### 常见坑

- 直接把请求路径拼到根目录后面（别人可以用两个点跳出你限定的目录，这是经典的安全漏洞，必须挡住）
- 把网页内容当纯文本发出去（浏览器会显示成一堆标签，内容类型要写成网页）

## 关卡 3 · 能点开文件、能下载，中文名也不乱

**建议用时**：35 分钟

### 做出这样就算过

点页面里的文件能打开：文本和图片直接在浏览器里显示，其它类型弹出下载；文件名里有中文的也要能正常下载，下载下来的文件名不能变成乱码；每次访问文件夹或文件都在窗口打印一行。

### 怎么想（步骤）

1. 判断要返回的是什么：按扩展名决定内容类型（网页、图片、文本各是一种，其它一律当下载处理）
2. 读文件内容并按字节返回；文件可能很大，先只处理几兆以内的，超大文件给出提示
3. 让浏览器下载：响应头里加一项告诉浏览器「按附件处理」，并把文件名写进去
4. 中文文件名的处理：文件名要按 URL 编码规则编码后再放进响应头，否则浏览器拿到的是乱码
5. 请求路径里也有中文（比如访问一个中文名文件夹），先要把路径里的编码还原成中文再去硬盘上找

### 要用到的语法点

- **按扩展名判断类型**：用一张小表把扩展名映射成内容类型；查不到就当二进制下载
- **二进制读取文件**：读出来直接是字节，正好可以发给浏览器
- **下载专用响应头**：有一项响应头告诉浏览器这是附件而不是要显示的内容
- **URL 编码与解码**：路径里的中文是编码过的，要先还原；响应头里的文件名要再编码回去
- **把异常变成状态码**：文件读不出来就返回 500，找不到就返回 404，别让服务崩掉

### 做完了自己检查

- [ ] 点一个图片能直接在浏览器里看到
- [ ] 点一个压缩包或文档会弹出下载
- [ ] 下载一个中文名文件，保存下来的文件名是正常中文
- [ ] 访问一个中文名文件夹能正常列出内容
- [ ] 读一个不存在或者没权限的文件时返回 500 或 404，服务继续活着

### 卡住看这里

- 中文文件名下载后变乱码：响应头里的文件名没编码
- 访问中文文件夹报 404：请求路径里的编码没还原成中文
- 浏览器显示成乱码文字：内容类型写错了，图片被当成了文本

### 常见坑

- 把文件内容当成文字读取（图片和压缩包会读坏，要用二进制方式）
- 忘记处理超大文件，一次读进内存导致程序卡死

## 关卡 4 · 加日志和口令，做成一份能拿出手的小工具

**建议用时**：35 分钟

### 做出这样就算过

程序做三件事：1 每次访问都往窗口和日志文件里写一行（时间、访问者的地址、请求路径、状态码）；2 用一个口令保护：地址后面要带上正确的口令参数才能访问，口令不对返回 403；3 启动时打印出「同一局域网的朋友可以用这个地址访问」以及本机在局域网里的地址。

### 怎么想（步骤）

1. 日志：在每次响应结束时写一行，格式统一；窗口打印一份，文件追加一份（别只在内存里留着）
2. 把公共的逻辑抽出来：不管响应哪种内容，最后都要写日志，所以用一个统一的收尾函数
3. 口令校验：从请求地址后面的参数里取出口令，跟程序里设定的比；不对就直接返回 403 并且不泄露任何文件信息
4. 打印局域网地址：你之前做过本机地址查询，复用那个思路；把地址和端口拼成一条可以直接发给同学的链接
5. 安全检查：启动时如果根目录是硬盘根或者用户主目录，直接拒绝启动并说明原因

### 要用到的语法点

- **取请求参数**：请求路径里问号后面的部分就是参数，用现成功能解析比手切字符串可靠
- **统一收尾写日志**：把写日志放进一个函数，每次响应结束都调用它
- **追加写日志文件**：追加模式，指定编码，一行一条
- **取本机局域网地址**：跟前面项目里一样，用网络功能拿主机名对应的地址
- **启动前检查**：在正式启动服务前判断根目录是否合理，不合理就退出

### 做完了自己检查

- [ ] 日志文件里能看到每一次访问的记录，时间、路径、状态码齐全
- [ ] 不带口令访问得到 403，并且页面上不显示任何文件信息
- [ ] 带对口令能正常浏览
- [ ] 启动时打印的局域网地址，用手机连同一个无线网能打开
- [ ] 把根目录设成硬盘根时程序拒绝启动并说明原因

### 卡住看这里

- 手机打不开：先确认在同一个无线网，再看电脑的防火墙是不是拦了（允许这个程序通过）
- 口令写在地址里很别扭：这是最简陋的方式，理解原理就行，正规做法是登录页面加会话（等你学网页后端再来做）
- 日志文件里时间不对：本地时间和标准时间不一样，用本地时间更符合直觉

### 常见坑

- 把这个服务放到公网上（家里电脑直接暴露在外面非常危险，只在自己家的局域网里用）
- 口令写在代码里还上传到公开仓库（真的要做成能公网用的东西，口令必须放在配置里，而且不能进仓库）
