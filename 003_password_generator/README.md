# 003 · 强密码生成器

> ★☆☆☆☆　难度 1.0 / 5　·　001–020 · 找回手感
> 2 ~ 3 小时，分 4 次　·　1 个文件（password_gen.py），约 130 行　·　只用 Python 自带功能（random 是自带的）
>
> **规矩：这份任务卡只给思路和语法点，一行代码都没有。代码由你自己写。**

**一句话**：按长度和字符种类生成随机密码，还能评估强度、批量生成不重复的

## 为什么做它

这是你第一个「真的会一直用下去」的程序：以后注册新账号，直接跑它拿一个密码。它同时也是理解「随机」的最好入口——你会发现真随机很难，而且「看起来随机」和「真的随机」是两回事。

## 做完是什么样

运行后它问你：密码多长？要不要数字、要不要符号、要不要大写？然后吐出几个候选密码，给每个标一句强度评价；还能一次生成 10 个互不相同的，并把历史记录追加保存到一个 txt 里。约 130 行，一个文件。

## 会练到的语法

`import random`　`random.choice / shuffle`　`for 与 while 循环`　`字符串拼接与 join`　`int() 与长度校验`　`函数与默认参数`　`set 去重`　`文件追加写入`　`enumerate`

> 新东西是「随机」和「集合去重」：想清楚哪些字符有资格被选中，剩下的交给随机。

## 关卡 1 · 先随便吐一个字符

**建议用时**：15 分钟

### 做出这样就算过

运行后屏幕上出现一个随机字符，比如 K 或者 7；再运行一次，很可能不一样。

### 怎么想（步骤）

1. 新建 password_gen.py
2. 准备一串候选字符（字母、数字、符号都写进去），就用一个字符串装起来
3. 引入 Python 自带的 random 功能，用它从这串候选里挑一个出来
4. 打印这个被选中的字符
5. 连续运行五次，观察结果是不是每次都不一样

### 要用到的语法点

- **import 引入模块**：random 是 Python 自带的，写一行 import 就能用，不用安装
- **random.choice**：从一串东西里随机挑一个出来
- **字符串就是字符的序列**：一串字符可以直接被当作可挑选的集合来用

### 做完了自己检查

- [ ] 运行五次，结果不总是同一个字符
- [ ] 把候选字符里只留数字，结果只出现数字
- [ ] 候选字符里加大写字母后，偶尔能抽到大写

### 卡住看这里

- 报错说模块不存在？检查 import 写对没有，random 是自带模块，不需要装
- 每次结果都一样？你可能没有真的调用随机函数，而是写死了一个字符

### 常见坑

- 把候选字符写成了一个列表又忘了加逗号，导致它们串成一个字符串（这一关问题不大，但要知道两者的区别）

## 关卡 2 · 生成指定长度的密码

**建议用时**：25 分钟

### 做出这样就算过

程序问你密码要几位，输入 8 就得到一个 8 位的随机密码；输入 0、-3 或 abc 时提示不合法并重新问。

### 怎么想（步骤）

1. 用 input 拿长度，再用 int 转成整数
2. 长度不合理（小于 1 或者大于 100）时提示重新输入
3. 用一个循环重复「随机取一个字符」这个动作，次数就是要的长度；把每次取的字符攒起来
4. 攒字符有两种办法：每次拼接到字符串末尾，或者先放进列表最后用 join 合并。两种都试一次，比较一下写法
5. 打印最终密码，并且把长度也一起打出来核对

### 要用到的语法点

- **for 循环与 range**：range 能生成一串数字用来数次数，数几次由你给的长度决定
- **字符串拼接**：把新字符接到已有字符串后面，但每次拼接都会新建一个字符串
- **列表与 join**：先把字符一个个放进列表，最后用 join 一次性粘成一个字符串，更高效也更好读
- **int()**：把文字变成整数；带小数的输入会失败，这一关可以先不管
- **长度校验**：用比较运算符和逻辑运算符判断数值是否在合理范围内

### 做完了自己检查

- [ ] 输入 8，输出正好 8 个字符
- [ ] 输入 1，输出 1 个字符
- [ ] 输入 0、-3、abc，程序都提示不合法并重新问，不崩
- [ ] 连续生成三次，同样长度但内容不同

### 卡住看这里

- 输出比要的长度多一个或少一个？循环次数可能算错，注意 range 的边界包含关系
- 拼接出来的密码里全是同一个字符？检查随机取字符的那句是不是写在循环外面了
- int 转换失败程序崩了：把转换那句放进 try 里，或者先检查输入是不是纯数字

### 常见坑

- 循环变量没用上但循环次数写死成了 8，换个长度就不对了
- 忘了在非数字输入时回到提问，导致后面用了一个不存在的值

## 关卡 3 · 让它听你的：选字符种类

**建议用时**：35 分钟

### 做出这样就算过

程序问三件事：要不要数字、要不要符号、要不要大写字母。只选数字时生成的密码全是数字；三种都选时，生成的密码里至少各有一个数字、一个符号、一个大写字母；三种都不选时它提示「至少选一种」并重新问。

### 怎么想（步骤）

1. 准备四份字符来源：小写字母、大写字母、数字、符号。小写字母永远包含
2. 问三个问题，根据回答把对应的字符来源合并成这一轮真正可用的字符池
3. 如果选择下来只剩小写字母一种（也就是三个都没选），提示并重新问
4. 先生成密码，再检查「每种被选中的类型是否都至少出现一次」；如果没做到，就重新生成，直到满足为止
5. 这个问题值得写成函数：给它长度和字符池，它返回一个合格的密码。这样主流程只需要调用

### 要用到的语法点

- **函数与默认参数**：括号里可以给参数一个默认值，调用时不传就用默认的
- **字符串相加拼字符池**：两串字符可以直接拼成更长的候选池
- **while 反复尝试**：生成后不满足条件就再生成一次，这类「试到合格为止」很常用
- **列表推导（可选）**：能一行写出的筛选逻辑；如果看不太懂，用普通循环完全一样
- **random.shuffle**：把一个列表里的顺序打乱，常用于「生成后再洗一遍」避免每类字符都集中在开头

### 做完了自己检查

- [ ] 只勾数字：生成的密码里没有任何字母和符号
- [ ] 三种全勾：连生成十次，每次都同时含数字、符号、大写字母
- [ ] 一个都不勾：程序提示并重新问，不生成空密码
- [ ] 密码中字符的顺序看起来是乱的，不是「先全部数字再全部字母」

### 卡住看这里

- 勾了符号却总是不出现符号？这种「必须包含」的检查要么单独补一个符号再打乱顺序，要么反复重试直到满足
- 重试很多次还是不合格？检查字符池是不是真的把符号拼进去了，可以先把字符池打印出来看一眼
- 生成的密码每类字符都挤在一起：生成完再打乱一次顺序

### 常见坑

- 把「要不要」的问题一律当成「要」，导致用户的否定回答被忽略
- 无限重试：如果字符池里根本没有某一类字符，重试永远不会成功，必须保证字符池和检查条件是一致的

## 关卡 4 · 加上强度评估和批量生成

**建议用时**：30 分钟

### 做出这样就算过

程序对每个密码给出「弱 / 中 / 强」的判断；能一次生成 10 个互不相同的密码；并把这次生成的密码追加保存到一个 txt 文件里，下次打开还能看到之前的记录。

### 怎么想（步骤）

1. 写一个评估函数：输入密码，输出强度等级。规则你自己定，但要说得通，比如按长度和包含的种类数两项打分，再映射到弱中强
2. 批量生成时用一个集合记录已经生成过的密码，如果新生成的已经在集合里就重来，保证 10 个互不相同
3. 生成完把密码逐条打印出来，前面带上序号
4. 把密码追加写进一个 txt：注意是追加而不是覆盖，否则上次的记录会被清空；每行一条，可以带上生成时间
5. 重新运行一次，确认文件里两批记录都在

### 要用到的语法点

- **set 集合**：自动去重的一堆东西，判断某个值在不在里面非常快
- **函数返回多个值**：需要同时给出密码和它的强度时，用逗号返回两个
- **文件写入的两种模式**：一种是清空重写，一种是接着后面追加，别用错
- **指定编码**：写文件时养成指定 UTF-8 的习惯，否则中文或特殊符号日后可能变成乱码
- **enumerate**：遍历时顺便拿到序号，比手动维护一个计数器省事

### 做完了自己检查

- [ ] 10 个密码互不相同
- [ ] 强度判断经得起检验：把长度改小、把种类减少，评价会变低
- [ ] txt 文件里能看到两批记录（说明是追加的）
- [ ] 文件里的内容打开后不是乱码

### 卡住看这里

- 批量生成卡住不动？集合里放不下新值时一直重试，检查生成的取值范围够不够大（长度太短又要求不重复确实可能凑不齐）
- 文件内容空了？多半用了覆盖模式，而你想要的是追加
- 中文注释写进文件变成乱码：写入时指定编码

### 常见坑

- 把强度评估写成「长度大于 12 就是强」，完全不管字符种类
- 用集合存最终结果却发现顺序乱了——集合不管顺序，要保序就用列表加一个用于判断的集合
