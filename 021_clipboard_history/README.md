# 021 · 剪贴板历史管理器

> ★★☆☆☆　难度 2.0 / 5　·　021–040 · 联网与窗口
> 3 小时左右，分 4 次　·　1 个文件（clipboard_history.py）+ 一个自动生成的历史文件，约 170 行　·　只用 Python 自带功能（tkinter 是自带的，不用装）
>
> **规矩：这份任务卡只给思路和语法点，一行代码都没有。代码由你自己写。**

**一句话**：自动记下你复制过的内容，能搜索、能一键填回去

## 为什么做它

写作业查资料的时候，你复制过的东西往往过一会儿就找不到了：上一段结论、刚才那个网址、同学发的那串号码。系统的剪贴板只记得最后一次，这个项目给你做一个记得住几十次的。它同时还是个很好的「后台小程序」练习：程序要在你不理它的时候自己盯着剪贴板。

## 做完是什么样

程序启动后安静地在后台跑：你把复制的内容一条条记下来（重复的不重复记），配上时间；按菜单可以列出历史、按关键词搜索、选一条重新填回剪贴板、看今天复制了多少次。退出后历史存在文件里，下次打开还在。约 170 行，一个文件。

## 会练到的语法

`tkinter 读写剪贴板`　`隐藏窗口`　`time.sleep 轮询`　`列表去重与集合`　`datetime 记时间`　`JSON 存读`　`菜单循环`　`字符串搜索`　`异常处理`

> 新东西是「轮询」：程序不能等剪贴板通知它，只能每隔一小会儿主动看一眼有没有变化。这是轮询和事件两种做法的区别，你以后做监控类程序都会遇到。

## 关卡 1 · 先读到剪贴板里现在有什么

**建议用时**：25 分钟

### 做出这样就算过

先复制一段文字到剪贴板，然后运行程序，屏幕上打印出你刚复制的那段内容；程序不会弹出任何窗口。剪贴板里是空的或不是文字时，打印一句提示而不是报错。

### 怎么想（步骤）

1. 新建 clipboard_history.py，引入自带的图形界面组件（我们只用它的剪贴板功能，不用真的开窗口）
2. 造一个隐藏的窗口对象，从它身上读剪贴板内容
3. 把读到的内容打印出来。先手工复制一句话，再运行，看能不能读到
4. 处理特殊情况：剪贴板里是图片、是空的、读不出来——这几种都要接住异常并给提示
5. 验证窗口确实没露出来：运行过程中不应该有任何界面弹出

### 要用到的语法点

- **import tkinter**：自带的图形界面组件，剪贴板读写是它的附带能力
- **造一个窗口但不显示**：必须有一个窗口对象才能操作剪贴板，但可以不把它显示出来
- **读剪贴板**：窗口对象上有专门的方法，读完还你一段文字
- **隐藏窗口**：有一个方法可以把窗口藏起来，调用它就不会弹窗
- **异常处理**：剪贴板里是图片时读出来可能不是文字，接住异常当「不是文字」处理

### 做完了自己检查

- [ ] 复制一段中文，运行程序，打印的内容跟剪贴板一致
- [ ] 复制一张图片后运行，程序提示「不是文字内容」而不是崩掉
- [ ] 运行过程中没有任何窗口弹出来
- [ ] 连续读两次结果一样（不会读一次就清空剪贴板）
- [ ] 程序结束后剪贴板内容没被改动

### 卡住看这里

- 报错说没有显示环境：tkinter 在某些纯命令行环境下不能建窗口，用自己的电脑直接跑就行
- 读到的是空字符串：可能你上一次的复制操作被别的程序覆盖了，重新复制一次再试
- 窗口一闪而过：忘了调用隐藏方法

### 常见坑

- 把窗口真的显示出来了（我们只需要它当剪贴板的「把手」，不需要界面）
- 以为读剪贴板会清空它（不会，读和写是两回事）

## 关卡 2 · 让它自己盯着：内容一变就记下来

**建议用时**：35 分钟

### 做出这样就算过

程序运行后进入循环：每隔一秒看一眼剪贴板，只要内容变了且没记过，就打印「第 3 条 已记录：xxx」，并带上时间。你先复制一段、再复制另一段，观察它一条条记下来。期间按中断键能干净地停下。

### 怎么想（步骤）

1. 把「读一次剪贴板」包进一个循环，循环里先记住上一次读到的内容，跟这次比：一样就跳过，不一样才算新内容
2. 再加一层去重：如果这条内容在历史里已经有了，不重复记（否则你来回复制同一句话会刷屏）
3. 每条记录存成一个字典：内容、时间、长度。全部攒进一个列表
4. 每次记新内容时打印序号、时间和内容前一小段（太长的截断显示）
5. 用异常处理接住中断键：按下去时打印「共记录 N 条」再退出。等待用原来的等待功能，别让循环空转吃满 CPU

### 要用到的语法点

- **循环轮询**：用一个永远成立的循环，每次看一眼，然后等一小会儿再看
- **记住上一次**：用一个变量存上一次读到的内容，比较之后更新它
- **列表去重**：判断新内容有没有在历史里出现过；历史里只存内容的话，可以先做一个内容列表
- **字典存一条记录**：时间、内容、长度各是一个键，比用列表按下标取清楚
- **截断显示**：内容太长时只显示前二十个字，后面加省略号

### 做完了自己检查

- [ ] 复制新内容时能在两秒内被记录下来
- [ ] 重复复制同一段内容不会产生第二条记录
- [ ] 每条记录都有时间，时间跟你实际操作的时间对得上
- [ ] 按中断键能干净退出并打印总数
- [ ] 程序只占很少的 CPU（不会满负荷空转）

### 卡住看这里

- 刚启动就把旧内容记了一遍：这是正常的（它看到的第一个内容就是上一次复制的），你可以选择跳过第一条
- 同一句话被记了很多次：去重只做了一半，检查你比较的是内容列表还是整个记录列表
- CPU 占满了：循环里没有等待，改成每次看一眼就等一会儿

### 常见坑

- 把「内容变了」的判断写成「内容不为空」（那样会不停重复记录）
- 等待时间设成 0，导致电脑风扇起飞

## 关卡 3 · 存进文件，还要能搜

**建议用时**：30 分钟

### 做出这样就算过

程序启动时读回上次的历史（打印「已载入 23 条历史」）；运行中新增的记录也会随时保存，直接关掉程序也不丢；菜单里多一个搜索功能：输入关键词，列出历史里所有包含它的记录（带序号和时间）。

### 怎么想（步骤）

1. 启动时先试着读历史文件：文件存在就载入，不存在就当作空历史（不要报错）
2. 每记录一条新内容就写一次文件——**别等到退出才写**，否则关窗口或断电就全丢了
3. 写文件用 JSON 格式，指定编码，关掉中文转义（否则中文会变成一串编码）
4. 搜索：循环历史，判断内容里有没有包含关键词。别忘了把两边都统一成小写，这样大小写都能搜到
5. 搜索结果为空时给一句提示，不要什么都不显示

### 要用到的语法点

- **文件存在判断**：先问一句文件在不在，再决定读还是当作空
- **JSON 存与读**：整个历史列表可以直接存成 JSON，读回来还是列表
- **关掉中文转义**：不关的话中文会被写成一串编码，文件看不懂
- **字符串包含判断**：判断一段文字里有没有出现关键词，有现成方法
- **统一大小写**：搜索前把两边都转成小写，这样搜什么大小写都能命中

### 做完了自己检查

- [ ] 重启程序后打印的历史条数跟上次退出时一致
- [ ] 记录几条后直接关掉程序（不要走退出菜单），重新打开还能看到
- [ ] 搜索关键词能命中，没命中的给提示
- [ ] 搜索英文时大小写不敏感
- [ ] 历史文件里中文能直接看懂

### 卡住看这里

- 重启后历史是空的：检查写入是不是只写在了退出分支里（要每记录一条就写）
- 文件读回来报错：JSON 写坏了，先把文件打开看一眼结构对不对
- 中文变成乱码或编码字符：写入时没指定编码，或者没关掉中文转义

### 常见坑

- 只在退出时保存一次（强制关掉程序就全丢）
- 读取时假设文件一定存在、格式一定正确（自己手改过的文件完全可能读不了，要接住异常）

## 关卡 4 · 填回去、看统计，做成真能用的工具

**建议用时**：35 分钟

### 做出这样就算过

菜单变成：1 查看历史 2 搜索 3 把某一条填回剪贴板 4 今日统计 5 清空历史 6 退出。选 3 时输入序号，程序把那条内容写回剪贴板，你直接去别的窗口粘贴就能拿到；选 4 时显示今天记了多少条、最长的一条多少字、有多少条是网址。

### 怎么想（步骤）

1. 写回剪贴板：用窗口对象的写入功能，先把剪贴板清空再写（顺序别反）
2. 统计今天：遍历历史，比较每条的时间日期跟今天是否一致；顺便统计总字符数里最长的那个
3. 判断网址：内容开头是不是那几个常见前缀（http、www），用开头判断就能做
4. 清空历史要二次确认，并且清空的是内存和文件两边
5. 把所有这些都放进菜单循环，输入不合法只提示不崩

### 要用到的语法点

- **写剪贴板**：先清空再写入，否则可能追加到旧内容后面
- **日期比较**：把记录的时间取出来跟今天的日期比，只要年月日部分
- **找最长**：遍历时记住当前最长的内容和它的长度，遇到更长的就替换
- **开头判断**：用字符串的开头判断识别网址
- **二次确认**：清空这种不可逆的操作必须先问一句

### 做完了自己检查

- [ ] 选一条填回剪贴板后，在浏览器地址栏粘贴能粘出那条内容
- [ ] 今日统计的数字跟你实际复制的次数对得上
- [ ] 网址识别不会把普通文字误判成网址
- [ ] 清空后历史文件和内存都空了，重启仍是空的
- [ ] 菜单输错、序号越界都只提示不崩

### 卡住看这里

- 粘贴出来还是旧内容：写入前没清空剪贴板
- 今日统计把昨天的也算进去了：比较时只取了时间字符串的前十个字符，可能格式对不上，先把两边的时间都打印出来看
- 序号对不上：显示的序号和列表下标差一，取的时候记得换算

### 常见坑

- 清空历史没有确认步骤（这是唯一不可逆的操作）
- 把写回剪贴板做成了「删除这一条」，用户以为丢了数据
