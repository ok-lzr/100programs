# 002 · BMI 与健康指标计算器

> ★☆☆☆☆　难度 1.0 / 5　·　001–020 · 找回手感
> 2 ~ 3 小时，分 4 次　·　1 个文件（bmi.py），约 140 行　·　只用 Python 自带功能
>
> **规矩：这份任务卡只给思路和语法点，一行代码都没有。代码由你自己写。**

**一句话**：按身高体重算出 BMI，判断区间，还能反推健康体重范围

## 为什么做它

BMI 不是给你贴标签用的，它是个最经典的「输入 → 计算 → 判断 → 给建议」练习。而且它有一个绝好的坑等你踩：区间边界到底归哪一边。学会处理边界，你以后写任何判断逻辑都会稳一点。

## 做完是什么样

程序问你要身高和体重（身高写 1.70 或 170 都认），算出 BMI 并给出一句结论；再输入家里几个人的数据，它一次把所有人的 BMI 和结论列出来，最后告诉你「按你的身高，健康体重应该在多少到多少公斤之间」。约 140 行，一个文件。

## 会练到的语法

`变量与算术`　`幂运算或连乘`　`if / elif / else 多分支`　`边界值判断`　`input 与 float 容错`　`while 循环重新询问`　`try / except`　`列表与嵌套列表`　`for 遍历`　`字典存一组数据`　`函数与返回值`

> 这一关的新东西是「多分支判断」和「输入容错」：真实用户什么都敢输，程序得接得住。

## 关卡 1 · 先算出一个 BMI 数字

**建议用时**：20 分钟

### 做出这样就算过

运行后输出一行：身高 1.70 米、体重 60 公斤的人，BMI 是 20.8（保留一位小数）。

### 怎么想（步骤）

1. 新建 bmi.py
2. 起两个变量存身高（用米）和体重（用公斤），先写死成 1.70 和 60
3. BMI 的公式是 体重 ÷ 身高的平方。平方可以写成身高乘自己，也可以用幂运算的写法
4. 把结果打印出来，保留一位小数，顺便把身高体重也一起打出来，方便核对
5. 把体重改成 75，看结果是不是变成 26.0 左右

### 要用到的语法点

- **幂运算**：Python 里有一个专门表示「几次方」的符号，是两个星号；不确定就用身高乘身高，效果一样
- **保留一位小数**：还是 f-string 里冒号加 .1f
- **round()**：另一个能把小数四舍五入的函数，但它返回的是数字不是文字，打印出来位数可能不稳定

### 做完了自己检查

- [ ] 1.70 / 60 得到 20.8
- [ ] 1.60 / 50 得到 19.5
- [ ] 改了体重，BMI 自动跟着变

### 卡住看这里

- 算出 0.2 或者特别小的数？多半是把身高直接除而没有平方
- 算出 20 出头但小数位很乱？加上保留一位小数的写法

### 常见坑

- 身高用了厘米却没换算成米，结果会小一万倍
- 把平方写成了乘以 2（那是两倍，不是平方）

## 关卡 2 · 分出胖瘦，还要经得住边界值

**建议用时**：30 分钟

### 做出这样就算过

同一个 BMI 值能自动得到一句结论：低于 18.5 偏瘦、18.5 到 23.9 正常、24 到 27.9 偏胖、28 及以上肥胖。每个结论后面再加一句人话建议。

### 怎么想（步骤）

1. 用 if / elif / else 写上四个分支，每个分支打印对应的结论
2. 关键一步：想清楚 18.5 这个数归哪一边，然后把你的判断写成「大于等于」或「小于」都能自圆其说的形式，不要出现同一个数字既是偏瘦又是正常
3. 依次把 BMI 设成 18.4、18.5、23.9、24、27.9、28 六个值跑一遍，把输出抄下来
4. 对照你的六行输出，检查有没有哪个值落进了两个结论或者一个都没落进去
5. 给每个结论补一句建议，比如正常区间就写「保持现在的作息」

### 要用到的语法点

- **if / elif / else 多分支**：从上往下第一个成立的分支执行，后面的一律不看——所以顺序本身就是逻辑
- **大于等于 / 小于**：比较运算符有两种写法，一种是只管大小，一种把相等也算进去，边界就靠它区分
- **布尔表达式组合**：用 and 写「大于等于 A 同时小于 B」这种区间条件

### 做完了自己检查

- [ ] 六个边界值各自的结论互不重叠、也不漏
- [ ] 18.5 落在「正常」，不会同时出现在偏瘦里
- [ ] 把顺序打乱（比如把肥胖的判断放到最前面）会出错——你能说出为什么

### 卡住看这里

- 出现两个结论一起打印？说明你写了两个独立的 if，而不是 if / elif；后者只会执行一个分支
- 健康区间判断总是跑到最后一个分支？检查 elif 的缩进是不是跟 if 对齐了
- 边界值归属想不清：建议先用「大于等于下界」这种写法，从头到尾保持一致的风格

### 常见坑

- 区间写成 18.5 到 23.9 但用大于而不是大于等于，导致正好 18.5 的人一个分支都不进
- 缩进不一致导致 elif 跑到别的 if 下面去了

## 关卡 3 · 改成会问的程序，而且不怕乱输

**建议用时**：35 分钟

### 做出这样就算过

程序分别问身高和体重；输 170 和输 1.70 都能算对；输 abc、输空行、输一长串空格，程序都只提示一句然后重新问，绝不崩。

### 怎么想（步骤）

1. 把写死的身高体重换成 input
2. 转换时要考虑容错：转换失败（用户输了字母）不能让程序崩，而是提示「请输入数字」再问一次。这需要 try / except 配合循环
3. 身高要接受两种输入习惯：数字大于 3 的当成厘米，自动除以 100；否则当成米
4. 值也要检查合理性：比如身高小于 0.5 米或大于 2.5 米、体重小于 10 公斤或大于 300 公斤，都提示重新输入
5. 把上面三种错误输入各测一次，再加一次正常输入，确认程序始终活着

### 要用到的语法点

- **try / except ValueError**：把可能转换失败的语句放 try 里，失败时跳进 except，程序不崩
- **while 与 continue**：用循环包住提问，输入不合格就用 continue 回到循环开头重新问
- **数值范围判断**：用比较运算符加 and 就能判断一个数在不在合理范围内
- **字符串方法 .strip()**：去掉输入两头多余的空格，防止「 170 」被当成非法输入

### 做完了自己检查

- [ ] 输入 170 / 60 和输入 1.70 / 60，算出同一个 BMI
- [ ] 输入 abc，程序提示并重新问，不崩
- [ ] 直接回车（空输入），程序提示并重新问
- [ ] 输入 3 米这种离谱身高，程序提示并重新问
- [ ] 没有一处因为用户输入而报红字

### 卡住看这里

- try 里的代码一多，你就不知道到底哪句出的错——每次只把真正可能失败的那一句放进去
- continue 之后程序直接退出了？确认 continue 在循环内部，而且缩进层级对
- 两种身高写法判断反了：大于 3 才当厘米，因为没人身高 3 米

### 常见坑

- except 后面什么都不写，把所有错误都吞掉，导致真正的 bug 也看不见——只接你预期的那个错误类型
- 在 except 里没有重新提问就直接往下算，用了一个没赋值的变量

## 关卡 4 · 算一家人，再反推健康体重

**建议用时**：35 分钟

### 做出这样就算过

程序里有一份名单（姓名、身高、体重），运行后一次把每个人的 BMI 和结论打印出来，并标出其中 BMI 最高的人；最后按第一个人的身高算出「健康体重范围是多少到多少公斤」。

### 怎么想（步骤）

1. 用列表装多个人的数据，每个人的数据本身也可以是一个小容器（字典或元组都行，字典更好读，因为你写得出「姓名」这种名字）
2. 把「算 BMI」和「判断结论」分别写成一个函数，这样名单循环时每人都调一次，逻辑不会重复
3. 用一个 for 把名单遍历一遍，逐人打印
4. 在遍历过程中记住目前最大的 BMI 和对应的人（用一个变量保存，遇到更大的就替换），遍历完打印出来
5. 写一个函数，输入身高，返回健康体重的下限和上限：下限靠 BMI 18.5 反推，上限靠 24 反推，公式是 BMI 乘身高的平方

### 要用到的语法点

- **列表**：一串有序的数据，用方括号装；装字典的列表可以表示一张表格
- **字典**：用名字取值的容器，比记住「第 0 个是姓名」清楚得多
- **for 遍历**：把列表里的每一项挨个拿出来处理
- **函数返回两个值**：return 后面用逗号隔开两个东西，调用时可以一次接住两个
- **打擂台找最大**：先假定第一个是最大，往后每遇到更大的就换掉它

### 做完了自己检查

- [ ] 名单里放 3 个人，一次运行全部输出，不重不漏
- [ ] BMI 最高的那个人被正确标出来
- [ ] 健康体重范围的数字，跟这个人 BMI 落在哪个区间是吻合的（可以自己反着验算一次）
- [ ] 换算逻辑只在函数里出现一次

### 卡住看这里

- 字典取值时用错了键名会报 KeyError，键名要跟定义时写的一模一样
- 找最大值时结果永远是第一个人？检查比较是不是写成了「大于等于」导致每次都被替换，或者替换语句缩进跑到了循环外面
- 两个返回值接不住？两个变量用逗号接收，顺序跟你 return 的顺序一致

### 常见坑

- 修改列表的同时又在遍历它，结果跳项或死循环
- 健康体重的上下限算反了（BMI 越小体重越轻，注意别把上下限写颠倒）
