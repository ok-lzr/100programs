# 024 · 本机网络信息查看器

> ★★☆☆☆　难度 2.0 / 5　·　021–040 · 联网与窗口
> 3 小时左右，分 4 次　·　1 个文件（net_info.py），约 150 行　·　只用 Python 自带功能
>
> **规矩：这份任务卡只给思路和语法点，一行代码都没有。代码由你自己写。**

**一句话**：看清自己的主机名、内网 IP、域名怎么变成 IP 的

## 为什么做它

「我的 IP 是多少」这个问题，答案其实有四个：内网 IP、公网 IP、IPv4、IPv6。大部分人只会打开一个网页查。这个项目让你自己把这几样都问出来，顺便搞清一件很多人一辈子没弄明白的事：**你输入一个域名，电脑是怎么找到那台服务器的**。

## 做完是什么样

程序打印一份信息卡：主机名、本机内网 IP、本机所有网络地址；再解析几个域名（比如你常上的网站）显示它们对应的 IP（可能有好几个）；还能查到你的公网 IP（需要联网，取不到时给出清楚提示而不是崩掉）。约 150 行，一个文件。

## 会练到的语法

`socket 主机名与地址`　`getaddrinfo 解析域名`　`gethostbyname`　`urllib 取网页内容`　`JSON 解析`　`异常降级`　`列表与去重`　`报告组装`　`写文件`

> 新东西是「域名解析」：域名只是给人看的名字，电脑之间通信用的是 IP，中间那一步叫解析，由专门的服务器完成。你会亲眼看到同一个域名可能对应好几个 IP。

## 关卡 1 · 先问出主机名和本机地址

**建议用时**：25 分钟

### 做出这样就算过

运行后输出两行：「主机名：xxx」和「本机地址：192.168.x.x」。把主机的名字拿去解析，把解析出来的所有地址都列出来（可能包含带冒号的 IPv6 地址）。

### 怎么想（步骤）

1. 新建 net_info.py，引入自带的网络功能
2. 问出主机名（电脑自己的名字）并打印
3. 用主机名去解析地址，拿到一个地址列表；把这些地址一条条打印出来
4. 观察一下：列表里有没有带冒号的地址？那是 IPv6 的写法，跟常见的四段数字不一样
5. 再用一个更全面的解析功能，能同时给出地址类型和端口等信息，打印出来对比一下跟你刚才拿到的有什么不同

### 要用到的语法点

- **取主机名**：自带的网络功能能问出这台电脑的名字
- **按主机名解析**：给一个名字，还你一串地址（可能是多个）
- **更全面的解析**：有一个功能能一次给出地址、类型、协议等信息，输出是列表里套元组
- **判断地址类型**：列表里的每一项都标了它是 IPv4 还是 IPv6
- **去重**：解析结果可能重复，用集合去一下重再打印

### 做完了自己检查

- [ ] 主机名打印出来了
- [ ] 本机地址被解析出来了，格式是四段数字（也可能有 IPv6 的）
- [ ] 主机名解析出来的地址里，至少有一个跟本机地址一致
- [ ] 地址类型能分辨出来（IPv4 和 IPv6 分开显示）
- [ ] 离线状态下也能跑（这一步不需要联网）

### 卡住看这里

- 解析报错说找不到主机：有的系统里主机名不在本地解析表里，可以换用「直接取本机地址」的方式，或者跳过这一步
- 打印出来一堆括号和引号：解析结果里每一项是元组，取你需要的那部分打印
- 地址是 127.0.0.1：这说明主机名对应的是本机回环地址，某些系统上是正常的

### 常见坑

- 把「主机名」和「用户名」搞混（一个是你电脑的名字，一个是你登录的账号）
- 看到一堆重复地址以为出错了（去重一下就好）

## 关卡 2 · 看域名怎么变成 IP

**建议用时**：30 分钟

### 做出这样就算过

程序里放一个域名列表（比如几个你常上的网站加上公共 DNS 服务器的域名），逐个解析并打印「域名 → IP（可能有多个）」，每个域名一行；解析失败的域名单独列出来并说明「解析失败」。

### 怎么想（步骤）

1. 把要解析的域名写成一个列表，先放三五个（建议放你自己会用的网站和公共服务域名，别放奇怪的地址）
2. 逐个解析，把结果去重后打印；重点是观察：同一个域名在不同时间、不同网络下解析结果可能不同，有的域名会给出多个 IP
3. 加异常处理：域名写错、断网、解析超时都会失败，失败的要单独记下来
4. 打印时对齐：域名一列、地址一列，地址有多个就换行或者用逗号连起来
5. 最后汇总「3 个域名解析成功，1 个失败」，失败的列出名字

### 要用到的语法点

- **解析域名**：给一个域名，还你一个地址；如果这个域名有多个地址，用更全面的解析功能能拿到全部
- **异常分类**：域名不存在和网络不通是两类问题，提示信息应该不一样
- **列表收集**：成功的和失败的分两个列表收集，最后统一打印
- **连接多个地址**：多个 IP 用逗号连接显示，比一行一个省地方
- **统一打印格式**：用格式化控制域名那一列的宽度

### 做完了自己检查

- [ ] 至少有一个域名解析出多个 IP（不少大站点都是这样，多试几个）
- [ ] 写一个不存在的域名，程序报「解析失败」并把它列进失败名单
- [ ] 断网后运行，程序不崩，全部报解析失败
- [ ] 汇总数字等于成功加失败
- [ ] 整个过程几秒内完成（解析不会卡很久）

### 卡住看这里

- 所有域名都解析失败：检查网络；如果网络正常，可能是这台电脑的解析服务有问题，试试换成公共 DNS 域名去解析
- 只拿到一个 IP：用的解析功能只给第一个，换成更全面的那个
- 报错中断了整个程序：异常没接住，一个失败就全停了

### 常见坑

- 把解析失败当成程序 bug（域名写错或断网都会失败，这是正常结果，要如实汇报）
- 反复高频解析同一个域名（解析结果是会缓存的，短时间内重复问意义不大）

## 关卡 3 · 查公网 IP，还得断网不崩

**建议用时**：30 分钟

### 做出这样就算过

程序通过网络上的公开接口查到自己的公网 IP 并打印；如果取不到（断网、接口不可用），打印「暂时查不到公网 IP：原因」，然后**继续把其它信息正常显示完**，绝不崩。

### 怎么想（步骤）

1. 选一个提供「你现在的公网 IP」的公开接口（这类接口直接返回一段文本或一小段 JSON，不需要注册）
2. 用自带的方式请求这个地址，把返回内容读出来；返回的可能是一段文本，也可能是 JSON，两种都处理一下
3. 把「取公网 IP」写成一个函数，成功返回地址，失败返回空——调用处根据有没有值来决定怎么显示
4. 所有网络相关的异常都要接住：连不上、超时、返回内容不是预期格式
5. 测试三种情况：正常、故意把地址改错、拔网线（或者关掉无线）

### 要用到的语法点

- **请求一个网址**：自带的网络请求功能可以打开一个地址并读出内容，不需要装库
- **设置超时**：请求时带上超时参数，避免网络不好时卡住几十秒
- **读取返回内容**：返回的对象可以按字节读出来，再解码成文字
- **JSON 解析与文本处理**：先试探性解析 JSON，解析不了就当成纯文本处理
- **失败返回空值**：函数用「返回空」表示失败，比抛异常更容易在调用处处理

### 做完了自己检查

- [ ] 联网时能查到公网 IP，且跟你在浏览器里查到的一致
- [ ] 把接口地址故意写错，程序提示查不到并继续显示其它信息
- [ ] 断网时程序不崩，其它本机信息照常显示
- [ ] 整个查询在三秒内返回（超时设得合理）
- [ ] 多次运行结果稳定（同一个网络下公网 IP 应该不变）

### 卡住看这里

- 请求卡很久：没设超时
- 返回内容是看不懂的字节：读出来之后忘了解码成文字
- 接口返回一段 JSON 但取错字段：先把整个返回内容打印出来看一眼结构

### 常见坑

- 把公网 IP 当成自己的「内网 IP」（两个完全不是一回事，一个是路由器对外的地址，一个是你电脑在局域网里的地址）
- 网络失败就让整个程序退出（信息卡应该「能拿到的都显示」）

## 关卡 4 · 做成一张信息卡，能导出

**建议用时**：35 分钟

### 做出这样就算过

程序把前面所有信息整理成一张排版整齐的信息卡：主机名、本机地址（全部）、公网 IP、解析结果、每部分都带一句人话解释；支持参数控制只看某一部分；能把信息卡写进一个文本文件。断网跑出来的信息卡上，公网 IP 那一栏写「未获取（离线）」。

### 怎么想（步骤）

1. 把每个部分各写成一个函数：取主机信息、取地址、查公网 IP、解析域名列表。每个函数只负责拿数据，不负责排版
2. 排版单独一个函数：把各部分数据拼成一张卡片，标题用分隔线，每部分之间空一行
3. 加运行参数：可以只看某一部分（比如只看公网 IP），不带参数就全部显示
4. 导出：把信息卡文字写进文件，带上生成时间
5. 离线测试：断开网络跑一次，检查信息卡依然完整、缺失的部分有明确说明

### 要用到的语法点

- **函数各管一段**：每个信息源一个函数，主流程只负责调用和排版
- **读运行参数**：从运行参数里取要显示的部分名，取不到就显示全部
- **用分隔线排版**：用重复的符号画一条线，把不同部分隔开，看起来像一张卡
- **写文件带时间**：文件开头写上生成时间，这样以后回头看知道是什么时候的
- **缺失值的统一写法**：约定好没取到的信息统一显示成什么，别一处写「无」一处写「未知」

### 做完了自己检查

- [ ] 信息卡的每一部分都有标题和一句解释
- [ ] 带参数运行时只显示指定的那一部分
- [ ] 导出的文件内容跟屏幕显示一致，中文不乱码
- [ ] 断网时信息卡依然能生成，公网 IP 那一栏有明确说明
- [ ] 信息卡里不会出现「None」这种程序内部的写法

### 卡住看这里

- 排版错位：中文和符号宽度不一样，先接受小错位，或者只用简单的分隔线
- 参数没生效：读参数时下标或者名字写错了，先把拿到的参数打印出来看
- 文件里出现 None：某个函数失败返回了空，排版时要统一替换成人话

### 常见坑

- 把公网 IP 和主机名这类信息发给别人（虽然不算秘密，但也没必要到处晒）
- 为了让卡片好看而隐藏失败信息（失败了就要写清楚失败，那才是真实状态）
