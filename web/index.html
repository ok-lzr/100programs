这个页面是怎么来的

纯原生 HTML / CSS / JavaScript，没有任何外部依赖，也没有后端。这个页面是只读的——它不加任何东西，只是把仓库里的进度画出来。

进度存在代码仓库的 progress.json 里：每完成一关都会记下完成时间，「最近动态」就是按时间倒序排出来的。数据文件里是一串真/假，第几个是 true，就代表第几关做完了。

怎么算「完成」
  • 一关完成：代码能跑出这一关要求的效果，并且过了一遍自检清单。
  • 一个项目完成：它的 3~5 关全部完成。
  • 连续过关：从你卡住的那一关往前数，中间没有断开的那一段。
