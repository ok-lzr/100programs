【一、项目背景与目标】

看国外菜谱时写着 “350°F”，实验室记录写的是 “298.15 K”，天气预报里又是摄氏度，每次
都要掏出手机换算一遍，还容易算错。这个工具把三种最常见的温标放在一个命令里互转，支持
一条命令直接出结果、支持交互式连续换算、也支持把一个 CSV 里的整列温度批量转完。

目标用户是三类人：做饭的人（烤箱温度）、学生与实验室人员（开尔文与摄氏）、以及需要
批量处理温度数据的普通办公用户（把导出的传感器 CSV 统一成摄氏再交给别人）。

做完之后应当能拿来干这些事：把 350°F 转成摄氏并显示成 “约 177 ℃”；把连续 24 小时
的开尔文记录一次性转成摄氏写入新文件；在交互模式里输错单位名时不崩溃，而是提示可用
的写法并重新询问。

【二、功能需求清单】

1. 核心功能
   1.1 三向换算：支持 C（摄氏）、F（华氏）、K（开尔文）两两互转，共 6 个转换方向。
   1.2 单位别名识别：摄氏接受 c、C、celsius、degC、℃；华氏接受 f、F、fahrenheit、
       degF、℉；开尔文接受 k、K、kelvin、degK。全角字符 ℃ 与 ℉ 必须识别。
   1.3 单次换算：命令行给定数值、源单位、目标单位，直接输出一行结果。
   1.4 批量换算：读取 CSV 或纯文本，把指定列的全部温度值转换后写出新文件，即使
       源文件有表头也要保留表头。
   1.5 交互模式：不带参数运行时进入循环，依次询问数值、源单位、目标单位，输出结果
       后询问是否继续，输入 q 或 quit 退出。

2. 输入与交互
   2.1 命令行形式：python temp_conv.py <数值> <源单位> <目标单位>
   2.2 转换表形式：python temp_conv.py --table 0,100,37 -f C -t F，逗号分隔多个数值。
   2.3 文件形式：python temp_conv.py --input in.csv --column 2 --from K --to C
       --output out.csv，--column 支持列序号（从 1 开始）或列名。
   2.4 交互模式下输入空行视为放弃本次输入，重新询问，不退出程序。
   2.5 所有输入都允许前后带空格；数值允许带正负号与小数点，如 +36.6、-40、.5。

3. 输出与展示
   3.1 单次换算输出格式：100.00 °C = 212.00 °F
   3.2 目标为开尔文时保留两位小数并加单位 K：37.00 °C = 310.15 K。
   3.3 批量换算在终端打印处理进度：共 24 行，成功 23 行，跳过 1 行。
   3.4 --verbose 时对每行输出 “第 3 行：298.15 K -> 25.00 °C”。
   3.5 结束时在终端打印一行统计：转换完成，耗时 0.01 秒。

4. 异常与边界处理
   4.1 数值无法解析为浮点数时，打印 “错误：无法识别的数值 'abc'”，退出码为 2。
   4.2 单位不在别名表中时，打印 “错误：不支持的单位 'xyz'，可用单位：C / F / K”。
   4.3 摄氏低于 -273.15、开尔文低于 0 时，打印警告 “警告：该温度低于绝对零度”，
       但仍按公式输出结果，便于教学演示。
   4.4 源单位与目标单位相同时直接原样返回，不做多余格式化误差处理。
   4.5 输入文件不存在时打印 “错误：找不到文件 xxx.csv”，退出码为 2；--column 指定的
       列不存在时打印可用列名列表后退出。
   4.6 空文件或全部行都为空时输出 “没有可转换的数据”，退出码为 0。

【三、技术要求与约束】

1. 语言与版本：Python 3.10 及以上。
2. 允许使用的库：仅使用标准库，需要 argparse、sys、csv、pathlib、dataclasses、
   typing、logging，禁止引入任何第三方包。
3. 禁止事项：禁止把换算公式硬编码成多份重复的 if-elif 分支；禁止在读写文件时
   不指定编码（必须显式 encoding="utf-8"）；禁止用 print 输出错误信息（用 logging
   或统一的输出函数）。
4. 代码组织：
   4.1 必须有 Unit 枚举或常量表，保存单位符号、别名集合与标准名。
   4.2 必须有 to_celsius(value, unit) 与 from_celsius(value, unit) 两个纯函数，
       其他方向的转换一律先转摄氏再转目标，保证只有两份公式。
   4.3 必须有 parse_value(text) -> float、normalize_unit(text) -> str、
       convert(value, src, dst) -> float 三个可单独测试的函数。
   4.4 必须把交互循环、单次执行、批量执行拆成三个函数，main() 只做参数分派。
5. 编码规范：所有公开函数写类型注解与 docstring（说明参数、返回值、异常）；
   变量命名用 snake_case，常量用大写；模块顶部写一行摘要 docstring。

【四、设计要点】

1. 数据结构：
   1.1 Unit 枚举成员：CELSIUS = ("C", "°C", ("c", "celsius", "degc", "℃"))，同构定义
       FAHRENHEIT 与 KELVIN。
   1.2 ALIAS_MAP：由别名小写形式到标准符号的字典，程序启动时由 Unit 自动构建。
   1.3 ConvertResult：dataclass，字段 source_value、source_unit、target_value、
       target_unit、warning（可为 None）。
2. 关键算法或流程：
   2.1 统一锚点法：摄氏 = (华氏 - 32) × 5 / 9；摄氏 = 开尔文 - 273.15；
       华氏 = 摄氏 × 9 / 5 + 32；开尔文 = 摄氏 + 273.15。
   2.2 换算流程：规范化源单位 -> 转摄氏 -> 转目标单位 -> 按目标单位格式化
       （C 与 F 两位小数、K 两位小数）-> 组装输出行。
   2.3 批量流程：用 csv.reader 读入全部行 -> 按 --column 定位索引 -> 逐行解析，
       解析失败记入 skipped 列表并继续 -> 写出时保留原表头与其余列不变。
3. 接口或命令设计：
   3.1 convert(value: float, src: str, dst: str, strict: bool = False) -> ConvertResult
   3.2 to_celsius(value: float, unit: str) -> float
   3.3 from_celsius(value: float, unit: str) -> float
   3.4 batch_convert(input_path, output_path, column, src, dst, verbose) -> tuple[int, int]
   3.5 命令行：位置参数 value、src、dst；可选 --table、--input、--output、--column、
       --from、--to、--verbose、--version。

【五、运行方式与示例】

1. 运行环境准备：无需安装依赖，确认 python --version 输出 3.10 以上即可。
2. 单次换算：
   python temp_conv.py 100 C F
   输出：100.00 °C = 212.00 °F
3. 使用转换表：
   python temp_conv.py --table 0,37,100 -f C -t K
   输出：
   0.00 °C = 273.15 K
   37.00 °C = 310.15 K
   100.00 °C = 373.15 K
4. 批量换算（in.csv 第 2 列是华氏温度）：
   python temp_conv.py --input in.csv --column 2 --from F --to C --output out.csv --verbose
   输出：
   第 0 行：68.00 °F -> 20.00 °C
   第 1 行：350.00 °F -> 176.67 °C
   共 2 行，成功 2 行，跳过 0 行。
5. 交互模式：
   python temp_conv.py
   输出：
   请输入温度值（q 退出）：36.6
   源单位（C/F/K）：c
   目标单位（C/F/K）：f
   36.60 °C = 97.88 °F
6. 异常输入示例：
   python temp_conv.py abc C F
   输出：错误：无法识别的数值 'abc'
   退出码：2
   python temp_conv.py 100 xyz C
   输出：错误：不支持的单位 'xyz'，可用单位：C / F / K
7. 极端值示例：
   python temp_conv.py -300 C K
   输出：警告：该温度低于绝对零度
   -300.00 °C = -26.85 K

【六、验收标准】

[ ] 命令行能完成 C→F、F→C、C→K、K→C、F→K、K→F 六个方向的换算且结果误差小于 0.01
[ ] 100 C F 输出 212.00 °F，0 C K 输出 273.15 K，-40 C F 输出 -40.00 °F
[ ] 单位别名 c、C、celsius、℃ 全部被识别为摄氏
[ ] 非数字输入返回退出码 2 并给出明确错误文本
[ ] 非单位输入的错误提示中包含可用单位列表
[ ] 低于绝对零度时先打印警告再输出结果
[ ] --table 支持逗号分隔多值与负数
[ ] --input/--output 能完成 CSV 批量换算并保留表头与其它列
[ ] --column 支持列序号与列名两种写法
[ ] 批量换算的统计行数量等于成功数加跳过数
[ ] 空文件输入时输出“没有可转换的数据”且退出码为 0
[ ] 交互模式输入 q 可退出，输入空行不会崩溃
[ ] 全流程未使用任何第三方库
[ ] 所有公开函数带类型注解与 docstring
