【一、项目背景与目标】

写驱动、看协议文档、调寄存器的时候，0xFF、0b1010、八进制权限 0755、以及 36 进制短码
会同时出现，靠计算器一个个敲很费劲。这个工具支持 2 到 36 之间任意进制互转，还顺带
支持同一进制下的加减乘除与按位运算，并且在输出时给出补码表示与分位显示。

目标用户是嵌入式与网络方向的开发者、准备计算机二级或期末考试的学生、以及学习编码
原理与位运算的初学者。设计重点是不依赖 int(x, base) 之外的任何黑魔法，进制解析与
格式化全部自己实现，便于理解原理；同时输入用不限长度的整数（Python 原生 int），
不做 32/64 位截断。

做完之后应当能拿来干这些事：一条命令把 255 转成 0xFF、0b11111111 与八进制 377；
把 0b1010 和 0xFF 相加得到十进制 265 与十六进制 0x109；查看 -5 在 8 位下的补码是
0xFB；用 base36 把自增 ID 变成短码。

【二、功能需求清单】

1. 核心功能
   1.1 任意进制互转：源进制与目标进制都在 2~36 之间，数字字符为 0-9 与 a-z（不区分大小写）。
   1.2 自动识别前缀：0b 二进制、0o 八进制、0x 十六进制、0d 十进制，
       也识别 # 前缀形式如 #FF。
   1.3 智能模式：--from auto 时按前缀与字符合法性推断进制（无前缀时默认十进制）。
   1.4 多进制一次性输出：--show-all 输出 2、8、10、16、36 五种表示。
   1.5 同进制运算：--op add|sub|mul|div|mod|and|or|xor|shl|shr，两个操作数同进制。
   1.6 补码表示：--twos-complement 8 输出指定位宽下的原码、反码、补码。
   1.7 位宽显示：--bits 16 把结果格式化成 16 位二进制并每 4 位插入空格。
   1.8 分位显示：--group 4 输出时每 4 位插入下划线，如 FF_FF_00_01。
   1.9 进制表：--table 输出 0~255 的十进制、二进制、八进制、十六进制对照表。
   1.10 批量：--file numbers.txt 每行一个数，逐行转换并输出。

2. 输入与交互
   2.1 单个转换：python baseconv.py 255 --from 10 --to 16
   2.2 带前缀自动识别：python baseconv.py 0xFF --from auto --to 10
   2.3 运算：python baseconv.py 0b1010 --op add 0xFF --from auto --to 10
   2.4 目标进制可多选：--to 2,16 一次输出两种结果。
   2.5 交互模式：不带参数运行，依次询问数值、源进制、目标进制，输入 q 退出。
   2.6 --upper 时十六进制输出大写字母（默认小写，--upper 后为 0xFF）。
   2.7 --prefix 强制输出带前缀（0b/0o/0x），--no-prefix 强制不带。
   2.8 小数支持：--float 允许小数转换（仅支持 2、8、10、16 进制），保留 10 位小数。
   2.9 负数支持：输入允许前导负号，输出同样带负号；与 --twos-complement 同时使用
       时按补码规则输出。

3. 输出与展示
   3.1 基础输出：255(10) = 0xff(16)
   3.2 多目标输出：
       255(10) = 11111111(2)
       255(10) = 377(8)
       255(10) = ff(16)
   3.3 --show-all 输出五行，包含 base36。
   3.4 运算输出：0b1010(2) add 0xff(16) = 265(10) = 0x109(16)
   3.5 补码输出：
       数值：-5，位宽 8
       原码：1000 0101
       反码：1111 1010
       补码：1111 1011（0xfb）
   3.6 位宽输出：--bits 16 时 255 显示为 0000 0000 1111 1111。
   3.7 --table 输出对齐的三列表格，每 16 行插入一行分隔。
   3.8 --json 输出 {"value":"255","from_base":10,"results":[{"base":16,
       "value":"ff","prefixed":"0xff"}]}。

4. 异常与边界处理
   4.1 进制不在 2~36 之间时打印 “错误：进制需在 2 ~ 36 之间”，退出码 2。
   4.2 数字中含该进制非法字符时打印 “错误：'19' 不是合法的八进制数（非法字符 '9'）”，
       退出码 2，并给出该进制允许的字符范围。
   4.3 空输入打印 “错误：数值不能为空”。
   4.4 前缀与 --from 指定冲突时（如 0xFF 且 --from 10）以显式 --from 为准并警告。
   4.5 除法在整数模式下整除，--float 时输出小数；除数为 0 时打印
       “错误：除数不能为 0”。
   4.6 移位位数超过 1000 时拒绝执行并提示上限。
   4.7 --twos-complement 的位宽需在 4~128 之间，且数值必须在位宽可表示范围内，
       否则提示 “错误：-5 无法用 4 位补码表示”。
   4.8 批量文件中的空行与 # 注释行跳过，非法行记录行号并继续。
   4.9 结果长度超过 10000 位时拒绝输出并提示改用 --file 输出到文件。

【三、技术要求与约束】

1. 语言与版本：Python 3.10 及以上。
2. 允许使用的库：仅使用标准库，需要 argparse、sys、json、re、pathlib、dataclasses、
   typing、fractions（小数模式可选）。
3. 禁止事项：禁止直接依赖 bin()、oct()、hex() 作为唯一实现路径（可以用于结果校验，
   但解析与格式化必须自己实现）；禁止用 eval 计算表达式；禁止把进制与字符表写成
   30 多个分支。
4. 代码组织：
   4.1 字符表：DIGITS = "0123456789abcdefghijklmnopqrstuvwxyz"，
       并预先构建 CHAR_TO_VALUE 字典。
   4.2 解析：parse_int(text, base, allow_prefix=True) -> int，
       内部逐字符按位累加 value = value * base + digit。
   4.3 格式化：format_int(value, base, upper=False, prefix=False) -> str，
       内部用 divmod 循环取余再反转。
   4.4 运算：apply_op(a, b, op) -> int（或 Fraction），运算符到函数的映射字典。
   4.5 补码：twos_complement(value, bits) -> tuple[str, str, str]
       （原码、反码、补码字符串）。
   4.6 main() 分派转换、运算、对照表、批量四种模式。
5. 编码规范：类型注解与 docstring；解析与格式化函数必须对 10 以外进制也正确处理；
   错误消息中给出非法字符与允许字符集；禁止使用 print 输出错误。

【四、设计要点】

1. 数据结构：
   1.1 ConvertResult：dataclass，字段 value: int、src_base: int、results:
       list[tuple[int, str]]（目标进制与字符串）。
   1.2 OPS：dict[str, Callable[[int, int], int]]，键为 add、sub、mul、div、mod、
       and、or、xor、shl、shr。
   1.3 前缀映射 PREFIX_MAP = {"0b": 2, "0o": 8, "0x": 16, "0d": 10, "#": 16}。
2. 关键算法或流程：
   2.1 解析算法：去掉前缀与符号 -> 转小写 -> 逐字符取 value = CHAR_TO_VALUE.get(ch)
       -> 若为 None 或 >= base 则报错并指出字符与位置 -> result = result * base + value
       -> 最后应用符号。
   2.2 格式化算法：若 value 为 0 直接返回 "0"；否则循环 divmod(abs_value, base)，
       把余数映射为字符并前插，最后加符号与前缀。
   2.3 自动识别顺序：有已知前缀按其进制；无前缀时若所有字符都属于二进制字符集且
       含有 0/1 之外判断不足以确定进制，则按十进制处理并在 --verbose 中说明推断结果。
   2.4 补码算法：位宽为 bits；正数原码即二进制左补零；负数先取绝对值转二进制补零，
       反码按位取反，补码为反码加一（丢弃溢出位）。
   2.5 位宽格式化：先 format_int 得到二进制串，左侧补零到 bits 位，再每 4 位插入空格。
   2.6 小数转换（--float）：整数部分按上述算法；小数部分反复乘 base 取整数位，
       最多 10 次，超过则截断并用 --verbose 提示精度损失。
3. 接口或命令设计：
   3.1 parse_int(text: str, base: int, allow_prefix: bool = True) -> int
   3.2 format_int(value: int, base: int, *, upper: bool = False,
       prefix: bool = False, group: int = 0) -> str
   3.3 detect_base(text: str) -> int
   3.4 convert(value_text: str, src_base: int, dst_bases: list[int], **opts)
       -> ConvertResult
   3.5 命令行：位置参数 value；可选 --from、--to、--op、--operand、--show-all、
       --bits、--twos-complement、--group、--upper、--prefix/--no-prefix、--float、
       --table、--file、--json、--verbose。

【五、运行方式与示例】

1. 运行准备：无需安装依赖。
2. 十进制转十六进制：
   python baseconv.py 255 --from 10 --to 16 --prefix --upper
   输出：255(10) = 0xFF(16)
3. 自动识别前缀：
   python baseconv.py 0b1010 --from auto --to 10
   输出：0b1010(2) = 10(10)
4. 一次输出多种进制：
   python baseconv.py 255 --show-all
   输出：
   255(10) = 11111111(2)
   255(10) = 377(8)
   255(10) = 255(10)
   255(10) = ff(16)
   255(10) = 73(36)
5. 进制运算：
   python baseconv.py 0b1010 --op add 0xFF --to 2,16
   输出：
   0b1010(2) add 0xff(16) = 100001001(2)
   0b1010(2) add 0xff(16) = 109(16)
6. 补码与位宽：
   python baseconv.py -5 --twos-complement 8
   输出：
   数值：-5，位宽 8
   原码：1000 0101
   反码：1111 1010
   补码：1111 1011（0xfb）
   python baseconv.py 255 --bits 16 --to 2
   输出：255(10) = 0000 0000 1111 1111(2)
7. 分位输出：
   python baseconv.py 4294967295 --to 16 --group 4
   输出：4294967295(10) = ffff_ffff(16)
8. base36 短码：
   python baseconv.py 1234567890 --to 36
   输出：1234567890(10) = 21i3v9(36)
9. 对照表：
   python baseconv.py --table --range 0-15
   输出：十六行 DEC/BIN/OCT/HEX 对照。
10. 异常输入示例：
    python baseconv.py 19 --from 8 --to 10
    输出：错误：'19' 不是合法的八进制数（非法字符 '9'，允许字符 0-7）
    退出码：2
    python baseconv.py 10 --from 1 --to 10
    输出：错误：进制需在 2 ~ 36 之间
    python baseconv.py 10 --op div 0
    输出：错误：除数不能为 0

【六、验收标准】

[ ] 255 转 16 进制输出 ff，加 --upper 输出 FF
[ ] 0xFF、0b1010、0o17、0d99 四种前缀都被正确识别
[ ] --from auto 对无前缀输入按十进制处理
[ ] --show-all 输出 2、8、10、16、36 五种表示
[ ] 任意两个 2~36 进制之间互转往返后可还原原值
[ ] 非法字符错误信息中包含该字符与允许字符范围
[ ] 进制越界（1 与 37）都返回退出码 2
[ ] 十种运算符全部可用，除法整除、取模结果符号与 Python 一致
[ ] 除数为 0 时给出明确错误且不抛异常栈
[ ] --twos-complement 8 对 -5 输出 fb
[ ] 补码位宽越界（如 -5 用 4 位）时给出可读错误
[ ] --bits 16 输出按 4 位分组且总长 16 位
[ ] --group 4 在结果中插入下划线
[ ] --table 输出可用于快速对照且对齐
[ ] 批量文件中的注释行与空行被跳过
[ ] 解析与格式化函数均未直接调用 bin/oct/hex 完成主要逻辑
[ ] 全程仅使用标准库

【七、可选扩展】

1. 增加 base64 与 base32 编码转换（用标准库 base64 模块但要说明与进制转换的区别）。
2. 增加 IEEE 754 单双精度浮点数的位模式展示（--ieee754 float32）。
3. 增加灰度与颜色转换：0xRRGGBB 拆分为 RGB 十进制。
4. 增加 --expr 支持简单表达式，如 "0xFF & 0x0F + 0b1"（需自己实现运算符优先级）。
5. 增加权限位解释：0755 输出 rwxr-xr-x。
6. 增加交互式 REPL，进入后可持续做多步换算。

【八、涉及知识点】

- 位置计数法原理与进制转换算法（乘基累加、除基取余）
- 任意进制字符表与 CHAR_TO_VALUE 映射

- 原码、反码、补码的表示与计算
- 二进制与十六进制的位对齐关系（4 位一组）
- 字符串格式化与分组插入分隔符
- 数字前缀字面量在 Python 中的写法
- 浮点数小数部分的进制转换与精度损失
- argparse 与运算符映射表驱动的命令设计
