# 100 个 Python 编程项目总览

> 全部项目使用 **Python** 实现，均由真实使用场景出发设计，难度由浅入深排列。
> 规模构成：**小型项目 50 个（001–050）+ 中型项目 40 个（051–090）+ 大型项目 10 个（091–100）= 100 个**。
> 每个项目位于独立文件夹中，文件夹内 `README.txt` 详述该项目的功能、需求、技术约束与验收标准。

## 使用建议

| 阶段 | 项目区间 | 目标 |
| --- | --- | --- |
| 入门打基础 | 001–025 | 掌握语法、标准库、文件与文本处理、网络基础 |
| 熟练能落地 | 026–050 | 掌握第三方库、GUI、多媒体、加密、系统编程 |
| 独立做应用 | 051–090 | 掌握数据库、Web 后端、爬虫、数据分析、机器学习 |
| 架构级训练 | 091–100 | 掌握分层架构、并发/分布式、工程化与部署 |

难度标记（五星制）：★☆☆☆☆ 入门 → ★★☆☆☆ 简单 → ★★★☆☆ 中等 → ★★★★☆ 偏难 → ★★★★★ 困难

各区间难度分布（保证由易到难不回落）：

| 区间 | 难度 | 说明 |
| --- | --- | --- |
| 001–014 | ★☆☆☆☆ | 纯计算与最基础命令行 |
| 015–034 | ★★☆☆☆ | 文件批处理、网络请求、编码与 AES 入门 |
| 035–060 | ★★★☆☆ | GUI、多媒体、数据库与内容生成 |
| 061–090 | ★★★★☆ | 采集分析、Web 后端、运维监控与 AI 入门 |
| 091–100 | ★★★★★ | 架构级大型系统 |

## 附录 · 项目结构约定

```
100programs/
├── 项目总览.md                  # 本文件：100 个项目的索引与规划
├── 001_temp_unit_converter/
│   └── README.txt               # 项目需求说明书（功能、要求、验收标准）
├── 002_bmi_health_calc/
│   └── README.txt
├── ...
└── 100_rag_qa/
    └── README.txt
```

每个 `README.txt` 统一包含以下 8 个部分：

1. 项目信息（难度等级、所属分类、建议工时、运行环境与依赖）
2. 项目背景与目标
3. 功能需求清单（编号、可验收）
4. 技术要求与约束
5. 数据结构 / 接口 / 算法设计要点
6. 运行方式与输入输出示例
7. 验收标准（自检清单）
8. 可选扩展方向与涉及知识点
