# 004 · 通用单位换算器

> ★☆☆☆☆　难度 1.0 / 5　·　001–020 · 找回手感
> 3 小时左右，分 4 次　·　1 个文件（unit_conv.py），约 150 行　·　只用 Python 自带功能
>
> **规矩：这份任务卡只给思路和语法点，一行代码都没有。代码由你自己写。**

**一句话**：长度、重量、面积、体积、速度、数据容量，一份系数表全部搞定

## 为什么做它

这一关真正教你的不是换算，而是「别写重复代码」。如果每个单位都写一个 if 分支，几十个单位能写到崩溃；用一张系数表配上两个函数，代码会短得让你惊讶。这是你第一次体会到「换一种数据结构，代码量差十倍」。

## 做完是什么样

运行后先选类别（长度 / 重量 / 面积 / 体积 / 速度 / 数据容量），再选从什么单位换成什么单位，输入数值就出结果；换错的、不认识的输入都会得到提示；连续换算的记录能一次性列出来，还能反向验算一次。约 150 行，一个文件。

## 会练到的语法

`字典与嵌套字典`　`函数与返回多个值`　`菜单式 while 循环`　`input 容错`　`列表追加与遍历`　`浮点格式化`　`sort 排序（可选）`　`enumerate 编号`

> 核心新知识是「字典套字典」：用一张表描述所有单位的换算系数，加一个新单位只需要在表里加一行。

## 关卡 1 · 先把一个换算写对

**建议用时**：20 分钟

### 做出这样就算过

程序能完成两个方向的厘米与米互转：输入 150 厘米得到 1.5 米，输入 1.5 米得到 150 厘米。

### 怎么想（步骤）

1. 新建 unit_conv.py
2. 先写死：一个变量存数值，一个变量存方向（是从厘米到米，还是反过来）
3. 用 if / else 分两种方向各算一次，1 米等于 100 厘米
4. 输出时把原数值、原单位、结果、目标单位一起打印出来，格式是「150 厘米 = 1.5 米」
5. 把数值改成 0.5 再跑一次

### 要用到的语法点

- **变量与浮点运算**：除法和乘法都会产生小数，注意别把结果打印成一长串
- **if / else 分方向**：两种方向两条路，先写清楚各自的公式
- **f-string 组合输出**：把数字和单位文字拼在一行里，数字部分可以控制小数位

### 做完了自己检查

- [ ] 150 厘米 → 1.5 米
- [ ] 1.5 米 → 150 厘米
- [ ] 0.5 米 → 50 厘米
- [ ] 输出的单位文字是跟着方向变的

### 卡住看这里

- 结果差 100 倍：检查乘除方向是不是写反了
- 想不出怎么让单位文字跟着变：用两个变量分别存原单位和目标单位，文字从变量里取

### 常见坑

- 把两个方向的公式都写成乘法（或者都写成除法）
- 单位文字直接写死成「米」，方向一变就显示错了

## 关卡 2 · 用一张表管住所有长度单位

**建议用时**：30 分钟

### 做出这样就算过

程序支持长度类的多个单位互转（毫米、厘米、米、千米，再加一个英寸）。关键是：代码里不再出现「厘米到米」「米到千米」这种成对的判断。

### 怎么想（步骤）

1. 想清楚一个统一思路：先把任何单位都换成同一个「中转单位」（长度就选米），再从中转单位换成目标单位
2. 用字典存系数：键是单位名，值是「1 个这种单位等于多少中转单位」
3. 写两个函数：一个负责「任意单位 → 中转单位」，一个负责「中转单位 → 任意单位」
4. 主流程变成三步：数值转成中转单位，再转成目标单位，然后打印。整个换算只需要两行公式
5. 检查一下：现在要加一个「英尺」，你需要在几个地方改代码？如果只有一处，说明你写对了

### 要用到的语法点

- **字典**：用名字取值，比一串 if 更好加新条目
- **中转单位法**：所有单位先统一到一个基准，两个单位之间就不用两两写公式
- **函数与参数**：把数值和单位名传进去，函数负责查表算结果
- **字典取值与键判断**：取不存在的键会报错，先判断键在不在字典里能避免崩溃

### 做完了自己检查

- [ ] 任意两个长度单位之间都能互转，包括自己转自己（结果应该等于原值）
- [ ] 1 米等于 100 厘米、1000 毫米、0.001 千米
- [ ] 1 英寸约等于 2.54 厘米
- [ ] 加一个新单位只需要在系数表里加一行，函数完全不用改
- [ ] 输入不存在的单位名时给出提示，不崩

### 卡住看这里

- 换出来总是差一个 10 的倍数：系数写错了，比如把「厘米等于多少米」写成了「米等于多少厘米」
- 系数方向统一一下：表里所有的值都表示「1 个本单位等于多少中转单位」，不要混着写
- 结果出现 0.30000000000000004 这类小数：浮点数天生的毛病，打印时保留合适的小数位就看不出来了

### 常见坑

- 表里的系数方向不统一，一半是「基准的几分之一」，一半是「几个基准」
- 单位名大小写不一致导致查不到（建议查表前统一转小写）

## 关卡 3 · 加上类别菜单

**建议用时**：35 分钟

### 做出这样就算过

程序先列出类别：1 长度、2 重量、3 面积、4 体积、5 速度、6 数据容量，你选一个之后，它再列出该类别的单位和系数，接着问你数值和源/目标单位，最后输出结果。

### 怎么想（步骤）

1. 把所有类别和它们各自的单位表组织成一个「字典套字典」的结构：外层键是类别名，内层是这个类别的单位系数表
2. 写一个函数负责列出某个类别下所有可用的单位（内层字典的键）
3. 主流程改成两级选择：先选类别（可以输入序号，也可以输入类别名），再选单位
4. 类别输入错了要能提示并重新问，不要直接退出
5. 每个类别至少放 3 到 5 个单位，注意它们的系数要以该类别自己的基准为准（比如重量用克或千克当基准都行，但要前后一致）

### 要用到的语法点

- **嵌套字典**：字典的值本身又是字典，这就构成了一张两层的表
- **遍历字典的键**：用循环把字典里所有单位名列出来，比手写一串打印更省事
- **字典的方法**：取所有键、取所有值、判断键是否存在，各有现成方法
- **菜单编号与映射**：把序号和类别名的对应关系也放进一个字典，用户输序号时先翻译成类别名
- **函数拆分**：「问类别」「问单位」「做换算」「打印结果」各自一个函数，主流程只剩几行

### 做完了自己检查

- [ ] 六个类别都能选进去，选错序号会提示
- [ ] 每个类别下至少三个单位可以互转，结果能对得上（自己拿常识验算：1 千米 1000 米、1 千克 1000 克、1 小时 3600 秒）
- [ ] 数据容量那类里，1 千字节等于 1024 字节这层关系是清楚的
- [ ] 主流程总共不超过 20 行

### 卡住看这里

- 字典套字典取错层：先取到类别那层，再取单位那层，分两步写更清楚
- 单位列表打印出来带一堆符号：打印时只是显示，不影响使用，可以专门整理一下格式
- 速度类的单位容易搞错：注意「米每秒」和「千米每小时」之间的换算不是整数倍

### 常见坑

- 面积单位系数算错：1 平方米等于 10000 平方厘米，不是 100
- 体积换算混淆：1 立方米等于 1000 升，不是 100
- 把类别名和单位名放在同一个字典里，导致取串了

## 关卡 4 · 容错、历史记录和反向验算

**建议用时**：35 分钟

### 做出这样就算过

输入数值可以带空格、负号、小数；换算完记录这一笔（类别、数值、源单位、结果、目标单位），连续换算几次后能输入一个指令把历史全部列出来；再输入另一个指令，程序把最近一次的结果反过来算回去，检查是不是等于原来的数值。

### 怎么想（步骤）

1. 数值输入用 try / except 接住非法输入，并且用字符串方法去掉两头空格
2. 每成功换算一次，就往一个列表里追加一条记录（用字典表示一条记录，字段名写清楚）
3. 给程序加两个指令：查看历史、退出。指令词要出现在提示语里，别让用户猜
4. 写一个反向验算功能：取最近一条记录，用它的结果、目标单位、源单位反过来算一次，跟原数值比，偏差很小就算通过
5. 把「数值 + 单位」输入成一行（中间用空格分开）试试，这样体验更顺；如果嫌麻烦，分成两次输入也可以

### 要用到的语法点

- **列表追加**：往列表末尾加一条记录用一个现成方法，别用加号拼（那会生成新列表）
- **字典表示一条记录**：每个字段一个键，打印时按字段名取，比记位置靠谱
- **数值比较的容差**：浮点算回来的值可能差一点点，判断时要允许一个小误差，不能要求完全相等
- **字符串切分**：把一行输入按空格切开，可以得到两个部分
- **enumerate 编号打印**：列历史时前面带上序号，方便你自己对着看

### 做完了自己检查

- [ ] 输入带空格的数值（比如「 12.5 」）能算对
- [ ] 输入 abc 时提示重新输入
- [ ] 换算 3 次后查看历史，三条记录齐全且顺序正确
- [ ] 反向验算通过，程序明确告诉你验算结果
- [ ] 全程没有任何一次因为输入问题崩掉

### 卡住看这里

- 一行输入的切分后拿到的其实是文字，别忘了转成小数；单位名不用转
- 历史列表打印出来是一堆花括号：用循环按字段名逐条打印，格式自己定得好看点
- 反向验算失败：先确认你记录的是「结果值 + 结果单位」，不要记错成输入值

### 常见坑

- 把历史记录列表定义在换算函数内部，每次调用都被清空
- 用「等于」判断浮点数，永远通不过——必须用容差比较
